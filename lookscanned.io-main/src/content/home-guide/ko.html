PDF 스캔한 것처럼 만들기란 무엇인가요?

PDF를 스캔한 것처럼 만든다는 것은 깨끗한 디지털 파일을 실제 사무실 스캐너의 흔적이 남은 페이지 이미지로 바꾸는 일입니다. 살짝 기울어진 각도, 입자감, 부드럽게 흐려진 초점, 회색이나 미색 종이 색감, 선택할 수 없는 텍스트가 바로 그 흔적입니다. 결과물은 여전히 일반 PDF이지만, 평판 스캐너를 거친 문서처럼 모든 페이지가 한 장의 그림이 됩니다.

이 도구는 브라우저에서 1분 안에 이 작업을 끝냅니다. PDF, 사진, 워드 파일을 넣고 실시간 미리보기를 보며 스캔 효과를 조정한 뒤 스캔본 같은 PDF를 다운로드하면 됩니다. PDF 스캔한 것처럼 만들기, PDF 스캔본처럼 만들기, 온라인 PDF 스캔 효과 중 어떤 말로 검색하셨든 작업과 단계는 같습니다.

온라인에서 3단계로 PDF 스캔한 것처럼 만들기

온라인에서 PDF를 스캔한 것처럼 만드는 작업은 3단계로 끝나며, 10페이지 파일이면 보통 20~60초가 걸립니다. 파일을 고르고, 미리보기를 보며 스캔 효과를 조정하고, 내보내면 됩니다. 설치도 계정도 필요 없고, 페이지가 한 번 로드되면 오프라인에서도 계속 작동합니다.

  1. 파일 선택. 스캐너를 열고 PDF, JPG, PNG, WebP, SVG, DOCX, XLSX, CSV, TXT, MD, HTML 파일을 끌어다 놓습니다. 워드, 엑셀, 텍스트 파일은 먼저 일반 텍스트 페이지로 변환됩니다. 레이아웃을 정확히 유지하려면 스캔하기 전에 문서를 PDF로 저장하세요.
  2. 스캔 효과 조정. 노이즈, 흐림, 회전, 밝기, 대비, 누런 톤 슬라이더를 움직이고, 회색조와 컬러를 전환하고, 얇은 스캐너 테두리를 추가합니다. 슬라이더를 움직일 때마다 미리보기가 바로 바뀝니다.
  3. 스캔 PDF 다운로드. 스캔 PDF 생성을 클릭합니다. 각 페이지가 설정대로 이미지로 렌더링되어 새 PDF에 저장되고, 곧바로 다운로드됩니다.

파일이 여러 개인가요? 일괄 스캔은 여러 문서에 같은 설정을 한 번에 적용하고 결과를 ZIP 파일 하나로 묶어 줍니다.

브라우저에서 PDF를 스캔한 것처럼 만들어도 안전한가요?

네. 스캔 효과는 사용자의 기기에서 렌더링됩니다. 페이지는 브라우저 안에서 동작하는 PDF 엔진으로 PDF를 읽고, 각 페이지를 캔버스에 그린 다음 그 위에서 노이즈, 흐림, 회전을 적용하고, 새 PDF를 로컬에서 만듭니다. 파일은 처리용 서버에 업로드되지 않으며 클라우드에 저장되지도 않습니다.

직접 확인할 수도 있습니다. 브라우저의 개발자 도구를 열고 네트워크 탭으로 전환한 다음 스캔을 실행해 보세요. 문서를 전송하는 요청은 하나도 없습니다. 이 앱은 프로그레시브 웹 앱(PWA)이므로 한 번 로드된 뒤에는 Wi-Fi를 꺼도 계속 작동합니다.

PDF 파일은 물론 이미지, 워드·엑셀 문서, 일반 텍스트 형식도 스캔한 것처럼 만들 수 있습니다. 여러 페이지로 된 PDF는 페이지 순서가 그대로 유지되고, 페이지마다 조금씩 다른 무작위 기울기가 적용되어 종이 뭉치를 한 장씩 스캐너에 넣은 문서처럼 보입니다.

  • 문서: PDF, DOCX(워드), XLSX(엑셀), CSV, TXT, 마크다운, HTML. PDF는 레이아웃이 그대로 유지됩니다. 워드, 엑셀, HTML 파일은 깔끔한 텍스트 페이지로 바뀌므로 서식이 중요하다면 먼저 PDF로 내보내세요.
  • 이미지: JPG, PNG, WebP, SVG, GIF, BMP. 이미지 한 장이 스캔 PDF 한 페이지가 됩니다. 자세한 내용은 이미지를 스캔본 PDF로 바꾸는 방법을 참고하세요.
  • 추가 기능: 텍스트 또는 이미지 워터마크, 위치와 크기를 조정할 수 있는 도장 또는 서명 이미지, 제목과 작성자 같은 PDF 메타데이터 편집.

스캔본 같은 PDF, 보내기 전에 어떻게 확인하나요?

잘 만든 스캔본 같은 PDF는 네 가지 간단한 확인을 통과합니다. 텍스트를 선택할 수 없고, 페이지가 조금씩 서로 다르게 기울어져 있고, 배경이 완전한 디지털 흰색이 아니며, 모든 페이지가 텍스트가 아닌 이미지가 되었기 때문에 파일 용량이 원본보다 눈에 띄게 큽니다.

  • 텍스트를 선택해 보세요. 한 줄을 커서로 드래그합니다. 실제 스캔본과 이 도구의 결과물에서는 단어가 강조 표시되지 않고 상자 하나만 선택됩니다.
  • 300~400%로 확대하세요. 글자 가장자리가 약간 부드럽고 종이에 희미한 입자감이 보여야 합니다. 완벽하게 날카로운 벡터 가장자리는 디지털 파일임을 드러냅니다.
  • 두 페이지를 비교하세요. 모든 페이지의 기울기가 똑같으면 기계로 만든 티가 납니다. 회전 편차를 0보다 크게 유지하세요.
  • 한 페이지를 인쇄해 보세요. 종이로 출력할 사본이라면 흐림과 노이즈를 적용한 뒤에도 작은 글씨와 서명이 잘 읽히는지 확인하세요.

스캐너 없이 PDF를 스캔한 것처럼 만들려면 어떻게 하나요?

이 사이트의 스캐너를 열고 PDF를 넣은 뒤 기본 설정을 그대로 두거나 노이즈, 흐림, 회전을 조정하고 스캔 PDF 생성을 클릭하세요. 각 페이지가 살짝 기울어지고 입자감 있는 회색조 이미지로 바뀌어 새 PDF로 저장됩니다. 프린터, 스캐너, 계정은 필요 없습니다.

이 스캔 효과 도구는 무료인가요?

네. 스캔은 무료이고 회원가입도 없으며, 직접 추가하지 않는 한 워터마크도 붙지 않습니다. Chrome 확장 프로그램도 무료입니다.

내 파일이 어딘가에 업로드되나요?

아니요. 파일은 브라우저에서 로컬로 처리되며 처리용 서버로 전송되거나 클라우드에 저장되지 않습니다. 첫 방문 이후에는 오프라인에서도 작동합니다.

스캔한 것처럼 만든 PDF에서도 텍스트를 선택할 수 있나요?

아니요. 실제 스캔본처럼 모든 페이지가 이미지가 되므로 텍스트를 선택, 검색, 복사할 수 없습니다. 나중에 편집 가능한 텍스트가 필요하다면 원본 파일을 보관해 두세요.

여러 페이지로 된 PDF도 스캔한 것처럼 만들 수 있나요?

네. 모든 페이지가 처리되며, 회전 편차 설정 덕분에 페이지마다 기울기가 조금씩 달라 기계로 찍어 낸 듯 완벽해 보이지 않습니다. 일괄 스캔으로 여러 파일을 한 번에 처리할 수도 있습니다.

워드 문서나 사진도 스캔한 것처럼 만들 수 있나요?

네. DOCX, XLSX, CSV, TXT, 마크다운, HTML 파일과 JPG, PNG, WebP, SVG 이미지는 먼저 페이지로 변환된 다음 같은 스캔 효과가 적용되어 스캔본 같은 PDF가 됩니다. 표, 로고, 특수 서식이 있는 워드 파일은 레이아웃이 정확히 유지되도록 먼저 PDF로 저장하세요.

해상도는 얼마로 설정해야 하나요?

기본값 2×(PDF 페이지 기준 약 144 dpi)는 읽기와 인쇄에 충분히 선명하면서 파일 용량도 작게 유지합니다. 작은 글씨가 있는 문서는 3×, 파일 용량이 가장 중요할 때는 1×를 사용하세요.

휴대폰에서도 작동하나요?

네. 웹사이트는 아무것도 설치하지 않고 최신 모바일 브라우저에서 실행됩니다. Chrome 확장 프로그램은 데스크톱 Chrome용입니다.
