What does it mean to make a PDF look scanned?

To make a PDF look scanned is to turn a clean digital file into page images that carry the marks of a real office scanner: slight tilt, grain, soft focus, a gray or cream paper tone and non-selectable text. The result is still a normal PDF, but every page is now a picture, exactly like a document that went through a flatbed scanner.

This tool does it in your browser in under a minute. You drop in a PDF, a photo or a Word file, tune the scan effect with a live preview, and download the scanned-looking PDF. Whether you search for make PDF look scanned, make a PDF look scanned online or make PDF looks like scanned, the task and the steps are the same.

Which settings make a PDF look scanned realistically?

A realistic scan comes from small values, not strong ones. The defaults — 1° rotation, 0.5° random variance per page, blur 0.3, noise 0.1, grayscale and 2× resolution — already look like an office scan. Pushing every slider to the maximum produces a result that looks edited rather than scanned.

Why make a PDF look scanned at all?

People make a PDF look scanned when a workflow expects paper: a landlord, school or HR team asks for a "scanned copy", a printed-and-signed look fits the context better, or the file should not offer selectable, copy-paste text. Designers also use the scan effect for mockups, zines and vintage-style handouts.

A scanned-looking PDF also flattens the content: text, form fields and layers become one image per page, so the file opens the same way everywhere. If you only need that flattening, read PDF to scanned PDF; if you need a plain grayscale copy, see how to convert a color PDF to black and white.

Use the scan look honestlyA scan effect changes how a document looks, not what it is. Do not use it to alter or pass off official records, IDs or signatures that are not yours. Some courts and agencies require text-searchable PDFs, so check the submission rules before you flatten a filing into images.

Make PDF look scanned: tool vs other methods

There are four common ways to make a PDF look scanned: a browser scan-effect tool, printing and physically scanning, photographing the printout with a phone, or editing page images in a raster graphics editor. The browser tool is the fastest and most consistent; the other three cost more time and give less control.

How to check a PDF that should look scanned before you send it

A convincing scanned-looking PDF passes four quick checks: text cannot be selected, pages are slightly and unequally tilted, the background is not pure digital white, and the file is noticeably larger than the original, because every page is now an image rather than text.

  • Try to select text. Drag the cursor across a line. In a real scan and in the output of this tool you get a box, not highlighted words.
  • Zoom to 300–400%. Edges of letters should be slightly soft and the paper should show faint grain. Perfectly sharp vector edges give a digital file away.
  • Compare two pages. Identical tilt on every page looks generated; keep rotation variance above 0.
  • Print one page. If the copy is going to paper, check that small print and signatures stay readable after blur and noise.

If your recipient needs searchable text, a scanned look is the wrong format; learn the difference in what is a scanned PDF.

Make PDF look scanned: frequently asked questions

How do I make a PDF look scanned without a scanner?

Open the scanner on this site, drop in the PDF, keep the default settings or adjust noise, blur and rotation, and click Generate Scanned PDF. Each page is turned into a tilted, grainy grayscale image and saved as a new PDF. No printer, scanner or account is needed.

Is this scan-effect tool free?

Yes. Scanning is free, there is no signup, and there is no watermark added unless you add one yourself. The Chrome extension is free as well.

Are my files uploaded anywhere?

No. Files are processed locally in your browser and are not sent to a processing server or stored in the cloud. The app even works offline after the first visit.

Will the text in my scanned-looking PDF still be selectable?

No. Every page becomes an image, just like a real scan, so text cannot be selected, searched or copied. Keep your original file if you need editable text later.

Can I make a multi-page PDF look scanned?

Yes. All pages are processed, and the rotation variance setting gives each page its own slightly different tilt so the document does not look machine-perfect. Bulk scan handles many files at once.

Can I make a Word document or a photo look scanned?

Yes. DOCX, XLSX, CSV, TXT, Markdown, HTML and JPG, PNG, WebP or SVG images are converted to pages first and then get the same scan effect, producing a scanned-looking PDF. For a Word file with tables, logos or special formatting, save it as PDF first so the layout is kept exactly.

What resolution should I use?

The default 2× (about 144 dpi for a PDF page) is sharp enough for reading and printing and keeps the file small. Use 3× for documents with fine print, 1× when file size matters most.

Does it work on a phone?

Yes. The website runs in modern mobile browsers without installing anything. The Chrome extension is for desktop Chrome.
