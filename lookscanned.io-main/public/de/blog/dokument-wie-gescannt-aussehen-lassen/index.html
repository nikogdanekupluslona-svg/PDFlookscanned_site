Wie lassen Sie ein Dokument wie gescannt aussehen?

Sie lassen ein Dokument wie gescannt aussehen, indem Sie jede Seite in ein Bild mit scannertypischen Fehlern verwandeln: eine kleine Schräglage, weiche Schärfe, leichtes Rauschen, Grautöne und manchmal einen warmen Papierton. Ein Browser-Tool erledigt das in Sekunden, sodass eine Word-Datei oder ein Google-Dokument als Papierscan durchgehen kann, ohne dass etwas gedruckt wird.

Ein echter Flachbett-Scan ist ein Foto von Papier. Das Glas ist nie ganz sauber, das Blatt liegt nie ganz gerade, und der Sensor fügt feines Sprenkelrauschen hinzu. Wenn Sie es digital wie gescannt aussehen lassen, reproduzieren Sie diese Eigenschaften absichtlich statt zufällig.

Das Ergebnis unterscheidet sich auch strukturell. Laut dem Team für digitale Barrierefreiheit der James Madison University „sind PDFs gescannter Dokumente oft nur Bilder von Dokumenten, ähnlich digitalen Fotografien, und enthalten typischerweise keinen lesbaren Text.“ Unser Tool erzeugt genau diese Art von Datei: Jede Seite wird zu einem JPEG-Bild in einem neuen PDF, sodass Text nicht mehr markierbar ist und Links sowie Formularfelder verschwinden.

Schritt für Schritt: ein Dokument wie einen Scan aussehen lassen

Der zuverlässige Weg, ein Dokument wie einen Scan aussehen zu lassen, hat vier Schritte: die Datei als PDF exportieren, das Scan-Tool öffnen, Drehung, Rauschen, Unschärfe und Farbe anpassen, dann das neue PDF herunterladen. Der PDF-Export ist es, der Schriften, Tabellen, Logos und Seitenumbrüche genau dort hält, wo Sie sie platziert haben.

  1. Dokument als PDF exportieren. Nutzen Sie in Microsoft Word Datei → Speichern unter (oder Exportieren) → PDF. In Google Docs nutzen Sie Datei → Herunterladen → PDF-Dokument. In einer Tabelle nutzen Sie Als PDF speichern oder Drucken als PDF. Überspringen Sie diesen Schritt nur bei reinen Text-Dokumenten.
  2. Scan-Tool öffnen. Gehen Sie in jedem modernen Browser, am Computer oder am Handy, zu pdflookscanned.com/scan und legen das PDF auf der Seite ab. Es ist kein Konto nötig.
  3. Scan-Einstellungen anpassen. Beginnen Sie mit den Standardwerten (Drehung 1°, Unschärfe 0,3, Rauschen 0,1, Graustufen), fügen Sie 0,5° Drehvarianz hinzu, damit Seiten unterschiedlich geneigt sind, und erhöhen Sie die Vergilbung auf 0,2–0,4, wenn Sie einen älteren Papierton wollen. Beobachten Sie die Live-Vorschau.
  4. Gescanntes PDF herunterladen. Klicken Sie auf Herunterladen, um ein neues PDF zu speichern, in dem jede Seite ein JPEG-Bild ist. Öffnen Sie es einmal in einem PDF-Betrachter, um zu bestätigen, dass Text nicht mehr markierbar ist und die Seiten klar lesbar sind.

Der gesamte Vorgang dauert für einen kurzen Brief oder ein Formular meist unter zwei Minuten. Längere Dateien brauchen mehr Zeit, weil jede Seite in Ihrem Browser-Tab gerendert, gefiltert und komprimiert wird.

DOCX hochladen oder zuerst als PDF exportieren?

Exportieren Sie immer zuerst als PDF, wenn das Layout wichtig ist. Das Scan-Tool akzeptiert DOCX-Dateien direkt, extrahiert dabei aber nur den reinen Text und setzt ihn in 11-Punkt-Helvetica mit 0,75-Zoll-Rändern auf A4-Seiten neu. Schriften, Tabellen, Bilder, Kopfzeilen, Logos und Briefköpfe gehen dabei verloren. Ein PDF wird unverändert übernommen, sodass jedes Detail erhalten bleibt.

Wir haben die direkte DOCX-Unterstützung für die Bequemlichkeit gebaut, nicht für die Originaltreue. Sie funktioniert gut für eine einfache Notiz, eine Liste oder einen Entwurf, bei dem nur die Wörter zählen. Für einen Brief mit Firmenbriefkopf, ein ausgefülltes Formular oder einen formatierten Bericht erzeugt der direkte Upload eine Seite, die dem Original in nichts ähnelt, was den Zweck verfehlt.

Wie Sie ein Word-Dokument wie gescannt aussehen lassen

Um ein Word-Dokument wie gescannt aussehen zu lassen, speichern Sie es aus Microsoft Word als PDF und lassen dieses PDF dann durch das Scan-Tool laufen. Words eigener PDF-Export erhält Schriften, Tabellen, Kopfzeilen, als Bild eingefügte Unterschriften und Seitenzahlen, die der Scan-Effekt anschließend in realistische Bildseiten verwandelt.

Ein Word-Dokument als PDF exportieren

  1. Öffnen Sie das Dokument in Microsoft Word und prüfen Sie die letzte Seite auf versehentliche leere Seiten.
  2. Wählen Sie unter Windows Datei → Speichern unter, wählen Sie einen Ordner und stellen Sie den Dateityp auf PDF. Auf dem Mac wählen Sie Datei → Speichern unter (oder Exportieren) und wählen PDF als Format.
  3. Belassen Sie die Optimierung bei „Standard“ für die schärfsten Ausgangsseiten.
  4. Speichern Sie, und legen Sie das neue PDF dann ins Scan-Tool.

Der Microsoft Support erklärt, dass Office-Desktop-Apps direkt als PDF speichern können, mit „Standard“-Qualität zum Drucken oder „Minimale Größe“ für kleinere Dateien. Wählen Sie Standard: Der Scan-Effekt fügt später seine eigene JPEG-Kompression hinzu, und eine schärfere Ausgangsseite ergibt nach Unschärfe und Rauschen klarere Buchstaben.

Die Microsoft-Seite beschreibt auch eine verwandte Option: „Wenn Schriften nicht in das Dokument eingebettet werden können, verwendet das PDF Bitmap-Bilder des Textes, damit das PDF genauso aussieht wie das Originaldokument.“ Diese Option allein erzeugt noch keinen Scan-Look, weil die Seite völlig gerade und sauber bleibt, aber sie zeigt, dass Text schon beim Export zu einem Bild werden kann.

Bietet Word auf Ihrem Computer keine PDF-Option, nutzen Sie stattdessen den Systemdrucker. Drucken Sie unter Windows auf den integrierten Drucker „Microsoft Print to PDF“. Öffnen Sie auf macOS den Druckdialog und wählen Sie PDF → Als PDF sichern. Beide erzeugen ein normales PDF, das Sie im nächsten Schritt wie gescannt aussehen lassen können.

Tipp für Word-FormulareFüllen Sie jedes Feld vor dem Export aus. Sobald Sie ein Word-Dokument wie gescannt aussehen lassen, werden Felder Teil eines flachen Bildes und lassen sich nicht mehr beschreiben – bewahren Sie also die ursprüngliche DOCX für spätere Änderungen auf.

Wie Sie ein Google-Dokument wie gescannt aussehen lassen

Um ein Google-Dokument wie gescannt aussehen zu lassen, laden Sie es mit Datei → Herunterladen → PDF-Dokument als PDF herunter und öffnen diese Datei dann im Scan-Tool. Das heruntergeladene PDF behält Schriften, Bilder und Seitenlayout des Dokuments bei, sodass die gescannte Version dem entspricht, was Sie im Editor sehen.

  1. Öffnen Sie das Dokument in Google Docs und wechseln Sie in die Druckansicht, um echte Seitenumbrüche zu sehen.
  2. Wählen Sie Datei → Herunterladen → PDF-Dokument (.pdf). Die Datei landet in Ihrem Ordner „Downloads“.
  3. Öffnen Sie das Scan-Tool in einem neuen Tab und legen Sie das PDF ab.
  4. Passen Sie die Einstellungen an, prüfen Sie die Vorschau und laden Sie die gescannte Kopie herunter.

Google Docs setzt in den USA meist standardmäßig auf die Seitengröße Letter, während direkte Text-Uploads in unser Tool A4 verwenden. Der Export als PDF vermeidet diesen Unterschied: Die gescannte Datei behält die Seitengröße des Dokuments bei, was wichtig ist, wenn der Empfänger sie auf Letter-Papier ausdruckt.

Derselbe Weg funktioniert auf dem Handy. Nutzen Sie in der mobilen Google-Docs-App die Freigabe-/Export-Funktion oder die Druckoption, um ein PDF zu speichern, öffnen Sie dann pdflookscanned.com im Handy-Browser und wählen Sie die Datei aus Dateien oder Downloads.

Wie Sie eine Excel-Tabelle oder CSV wie gescannt aussehen lassen

Um eine Tabelle wie gescannt aussehen zu lassen, speichern Sie die Excel-Arbeitsmappe zuerst als PDF und wenden dann den Scan-Effekt an. Legen Sie eine XLSX- oder XLS-Datei direkt ins Tool, wird jedes Blatt in CSV-Text auf A4-Seiten umgewandelt, wodurch Gitterlinien, Spaltenbreiten, Zahlenformate, Farben und Diagramme verloren gehen.

Tabellen brauchen mehr Vorbereitung als Briefe, weil sie selten von sich aus auf eine Seite passen. Öffnen Sie vor dem Export die Seitenlayout- (oder Seite-einrichten-)Einstellungen, legen Sie die Ausrichtung fest und wählen Sie „Alle Spalten auf eine Seite anpassen“, damit eine breite Tabelle nicht über mehrere Papierseiten reißt.

  1. Legen Sie den Druckbereich fest, stellen Sie Ausrichtung und Skalierung ein und prüfen Sie die Druckvorschau.
  2. Wählen Sie Datei → Speichern unter → PDF, oder drucken Sie unter Windows auf „Microsoft Print to PDF“ bzw. unter macOS auf Als PDF sichern.
  3. Legen Sie das PDF ins Scan-Tool und behalten Sie die Auflösung bei 2× oder höher, weil kleine Tabellenziffern mehr Pixel brauchen.

Eine rohe CSV-Datei ist der eine Fall, in dem direkter Upload sinnvoll ist. Das Tool druckt die kommagetrennten Werte als reinen Text auf A4-Seiten, was wie ein einfacher Datenausdruck wirkt. Wollen Sie eine formatierte Tabelle, öffnen Sie die CSV stattdessen in einer Tabellen-App und exportieren Sie ein PDF.

Wie Sie ein Foto wie ein gescanntes Dokument aussehen lassen

Um ein Handyfoto wie ein gescanntes Dokument aussehen zu lassen, schneiden und begradigen Sie es zuerst mit der eingebauten Dokumentenerkennung Ihres Handys, dann legen Sie das Bild ins Scan-Tool. Das Tool platziert jedes JPG oder PNG in seiner Originalgröße als eine PDF-Seite und fügt Grauton, Rauschen und Unschärfe hinzu, schneidet aber nicht zu, richtet nicht gerade und korrigiert keine Perspektive.

Die eingebaute Scan-Funktion übernimmt die Geometrie. Auf einem iPhone kann die Notizen-App von Apple ein Papierdokument scannen mit automatischer Kantenerkennung; die Dateien-App bietet denselben Scanner. Viele Android-Handys enthalten einen Dokumentmodus in der Kamera oder in der Dateien-App. Nutzen Sie einen davon, um eine flache, rechteckige Seite zu erhalten, bevor Sie die Scan-Optik anwenden.

  • Licht: Fotografieren Sie bei gleichmäßigem Tageslicht ohne Blitz, damit auf glänzendem Papier keine Lichtreflexe entstehen.
  • Winkel: Halten Sie das Handy parallel zur Seite; auch bei automatischer Korrektur macht ein steiler Winkel die entfernte Kante unscharf.
  • Hintergrund: Legen Sie das Blatt auf eine dunkle, einfarbige Unterlage, damit die Kantenerkennung die Ecken findet.
  • Format: Jedes Bild wird auf eine A4-Seite skaliert und zentriert (Querformat für breite Bilder); JPG und PNG werden unverändert eingebettet, während WebP, GIF, BMP und SVG in JPEG umgewandelt werden, mit einer längeren Kante von höchstens 2.200 px.

Eine Bilddatei wird immer zu einer einzigen einseitigen PDF. Hat ein Vertrag fünf fotografierte Seiten, kombinieren Sie diese zuerst: Öffnen Sie auf einem Mac alle Bilder in der Vorschau, wählen Sie sie in der Seitenleiste aus und wählen Sie Drucken → Als PDF sichern; wählen Sie unter Windows die Fotos aus, öffnen Sie Drucken in der Fotos-App und wählen Sie „Microsoft Print to PDF“. Lassen Sie dann dieses zusammengeführte PDF wie gescannt aussehen.

Unsere Anleitung zum Umwandeln von Bild in gescanntes PDF behandelt Fotos noch ausführlicher.

Wie lassen Sie ein unterschriebenes Formular wie gescannt aussehen?

Um ein unterschriebenes Formular wie gescannt aussehen zu lassen, ohne zu drucken, exportieren Sie das ausgefüllte Formular als PDF, fügen Ihr eigenes Unterschriftsbild über die Stempel-/Unterschrift-Option des Tools hinzu, stellen Position und Größe ein und wenden den Scan-Effekt an. Die Unterschrift wird zusammen mit dem Text in das Seitenbild eingebettet, genau wie Tinte auf einem echten Scan.

Der Kreislauf aus Drucken, Unterschreiben und Scannen kostet Zeit und Geld. Die Bibliothek der East Tennessee State University verlangt zum Beispiel 10 Cent pro Seite für Schwarz-Weiß und 25 Cent für Farbdruck, und danach brauchen Sie trotzdem noch einen Scanner. Digitales Unterschreiben spart beide Schritte.

Ihr Unterschrifts- oder Stempelbild hinzufügen

  1. Unterschreiben Sie ein weißes Blatt mit einem dunklen Stift, fotografieren Sie es und schneiden Sie eng um die Unterschrift zu. Eine PNG mit transparentem Hintergrund wirkt am besten.
  2. Öffnen Sie im Scan-Tool die Stempel-/Unterschrift-Option und laden Sie das Bild hoch.
  3. Verschieben Sie es mit den Reglern für horizontale und vertikale Position auf die Unterschriftslinie und passen Sie die Größe an, bis sie zur Linienlänge passt.
  4. Wenden Sie Graustufen, leichte Unschärfe und Rauschen an, und laden Sie herunter. Die Unterschrift teilt sich nun dieselbe Textur wie der gedruckte Text.

Elektronische Unterschriften sind in den USA weithin anerkannt. Der ESIGN Act besagt: „Einer Unterschrift, einem Vertrag oder einem anderen Dokument im Zusammenhang mit einer solchen Transaktion darf die rechtliche Wirkung, Gültigkeit oder Durchsetzbarkeit nicht allein deshalb abgesprochen werden, weil es in elektronischer Form vorliegt.“ Der IRS geht noch weiter und listet unter den zulässigen Formen der elektronischen Signatur „ein gescanntes oder digitalisiertes Bild einer handschriftlichen Unterschrift, das an eine elektronische Aufzeichnung angehängt ist.“

Gerichte können das Gegenteil bevorzugen. Das US-Bezirksgericht für den Northern District of California erlaubt E-Filern für viele Dokumente eine konforme „/s/“-Unterschrift statt eine unterschriebene Seite einzuscannen. Befolgen Sie immer die konkreten Regeln des jeweiligen Empfängers des Formulars.

Scan-Optik ehrlich einsetzenEin Scan-Effekt verändert, wie eine Seite aussieht, nicht ob sie echt ist. Unterschreiben Sie nur mit Ihrer eigenen Unterschrift und stempeln Sie nur Dokumente, zu denen Sie berechtigt sind. Verändern Sie niemals offizielle Aufzeichnungen, Ausweise oder die Unterschrift einer anderen Person. Manche Gerichte und Behörden verlangen durchsuchbare PDFs, prüfen Sie also die Einreichungsregeln, bevor Sie eine reine Bilddatei versenden.

Jeder Dokumenttyp braucht einen etwas anderen Weg und andere Ausgangseinstellungen. Formatierte Textdokumente laufen über PDF-Export mit sanften Einstellungen, Tabellen brauchen höhere Auflösung, Fotos müssen zuerst zugeschnitten werden, und unterschriebene Formulare brauchen das Unterschriftsbild, bevor der Scan-Effekt angewendet wird. Welche Einstellungen lassen ein Textdokument wie gescannt aussehen?

Für textlastige Dokumente sind realistische Einstellungen dezent: eine Drehung von 0,5–1,5°, Unschärfe um 0,3, Rauschen zwischen 0,05 und 0,2, Farbraum Graustufen und 2× Auflösung. Stärkere Werte lassen die Seite eher beschädigt als gescannt wirken und können Kleingedrucktes schwer lesbar machen.

Jeder Regler hat einen festgelegten Bereich, sodass Sie denselben Look später reproduzieren können. Hier sind die Regler mit Bereich, Standardwert und unserem Rat für Briefe, Verträge und Berichte.

Drehung (−10° bis 10°, Standard 1°)
0,5–1,5° wirkt wie ein von Hand aufgelegtes Blatt. Über 3° liest sich nachlässig.
Drehvarianz (0 bis 10°, Standard 0,5°)
0,3–0,8° gibt jeder Seite eine leicht andere Neigung, wie beim echten Einzug-Scan.
Unschärfe (0 bis 1, Standard 0,3)
0,2–0,4 für Fließtext in 10–12 pt; niedriger für Kleingedrucktes und Fußnoten.
Rauschen (0 bis 1, Standard 0,1)
0,05–0,2 fügt Sensorsprenkel hinzu, ohne die Lesbarkeit zu beeinträchtigen.
Helligkeit und Kontrast (0 bis 2, Standard 1)
Kontrast 1,1–1,2 ahmt einen Kopierer-Look nach; Helligkeit 1,05 hellt graue Hintergründe auf.
Vergilbung (0 bis 2, Standard 0)
0,2–0,5 lässt an nicht-weißes oder gealtertes Papier denken; bei 0 belassen für scharfes Büropapier.
Farbraum (Graustufen oder Farbe, Standard Graustufen)
Graustufen für die meisten Bürodokumente; Farbe nur, wenn Logos oder Stempel ihre Farbe behalten müssen.
Rand (an/aus, Standard aus)
Fügt eine dünne dunkle Rahmenlinie um die Seite hinzu, wie die Kante eines Scannerdeckels.
Auflösung (1× bis 3×, Standard 2×)
2× sind rund 144 dpi; 3× sind rund 216 dpi für Kleingedrucktes, bei größerer Dateigröße.

Für einen tieferen Blick auf jedes Artefakt und fertige Vorlagen siehe unsere Anleitung zum Scan-Effekt. Brauchen Sie die Seite nur in Schwarz-Weiß, erklärt unsere Anleitung zu Graustufen vs. Schwarz-Weiß den Unterschied.

Lesbarkeit zuerstZoomen Sie die Vorschau auf 100 % und lesen Sie die kleinste Zeile auf der Seite, etwa eine Fußzeile oder eine Tabellennotiz. Zögern Sie bei einem Zeichen, senken Sie die Unschärfe um 0,1 oder erhöhen Sie die Auflösung um 0,5×.

Wie Sie mehrseitige und Stapel-Dokumente mit Scan-Effekt versehen

Mehrseitige PDFs werden in einem Durchgang bearbeitet: Jede Seite erhält dieselben Einstellungen, und die Drehvarianz fügt jeder Seite eine andere zufällige Neigung hinzu. Für viele einzelne Dokumente verarbeitet die Stapelseite unter /scan/bulk mehrere Dateien und lädt sie alle als ein ZIP herunter, mit einem gescannten PDF pro Quelldatei.

Die Seitenzahl beeinflusst Zeit und Größe. Jede Seite wird bei der gewählten Auflösung gerendert und als JPEG-Bild gespeichert, sodass ein 30-seitiger Bericht bei 3× spürbar länger dauert und eine viel größere Datei ergibt als derselbe Bericht bei 2×. Für lange Dokumente ist 2× meist die bessere Balance.

Größenlimits spielen eine Rolle, wenn Sie Dateien online einreichen. USCIS begrenzt zum Beispiel jede Beweisdatei bei der Online-Einreichung auf 12 MB, und der Northern District of California bittet Einreicher, Beweisstücke über 50 MB zu teilen. Ist Ihr gescanntes PDF zu groß, senken Sie die Auflösung auf 1,5× oder teilen Sie das Quell-PDF vor der Verarbeitung.

  • Stapel-Scan: Öffnen Sie /scan/bulk, fügen Sie alle Dateien hinzu, stellen Sie gemeinsame Einstellungen ein, laden Sie das ZIP herunter.
  • Chrome-Erweiterung: Die Erweiterung mit Seitenleiste nutzt dieselbe Engine und akzeptiert mehrere Dateien auf einmal.
  • Konsistenz: Nutzen Sie identische Einstellungen für Dokumente, die scheinbar vom selben Scanner stammen sollen.

Wie Sie prüfen, ob die gescannte Kopie echt wirkt

Prüfen Sie eine gescannte Kopie in drei Durchgängen: Öffnen Sie das heruntergeladene PDF und versuchen Sie, Text zu markieren, zoomen Sie auf 100 %, um das kleinste Gedruckte zu lesen, und betrachten Sie dann die ganze Seite auf Armlänge, um Schräglage und Ton zu beurteilen. Ein überzeugendes Ergebnis lässt keine Textmarkierung zu, bleibt lesbar und wirkt gleichmäßig unperfekt.

  1. Markierungstest. Drücken Sie Strg+A oder Cmd+A in einem PDF-Betrachter. Nichts sollte hervorgehoben werden, weil jede Seite jetzt ein Bild ist.
  2. Lesbarkeitstest. Lesen Sie Ziffern in Daten, Beträgen und Referenznummern laut vor. Das sind die Zeichen, die Menschen zuerst prüfen.
  3. Konsistenztest. Blättern Sie durch alle Seiten. Die Neigung sollte leicht variieren, während Ton und Rauschen gleich bleiben, wie bei einer einzigen Scan-Sitzung.
  4. Größentest. Sehen Sie sich die Dateigröße an und vergleichen Sie sie mit dem Limit des Portals oder E-Mail-Dienstes, den Sie nutzen werden.
  5. Metadatentest. Öffnen Sie die Dokumenteigenschaften. Zeigt der Titel oder Autor noch einen Arbeitsnamen, bearbeiten Sie ihn in den Metadatenfeldern des Tools und exportieren Sie erneut.

Den Metadaten-Schritt vergisst man leicht. Das Tool lässt Sie Titel, Autor, Thema, Stichwörter, PDF-Erzeuger und Anwendung setzen, sodass das Eigenschaften-Panel das Dokument klar beschreiben kann, statt einen alten Arbeitstitel zu zeigen.

Kann ich ein Dokument auf dem Handy wie gescannt aussehen lassen?

Wie lasse ich ein Dokument wie gescannt aussehen, ohne es zu drucken?

Exportieren Sie die Datei als PDF und wenden Sie im Browser einen Scan-Effekt an. Das Tool rendert jede Seite als Bild mit Schräglage, Unschärfe, Rauschen und Grauton, sodass Sie die Optik eines Papierscans ohne Drucker oder Scanner erhalten.

Funktionieren Hyperlinks noch, nachdem ich es wie gescannt aussehen lasse?

Nein. Jede Seite wird zu einem JPEG-Bild in einem neuen PDF, sodass Hyperlinks, Lesezeichen, Formularfelder und markierbarer Text verloren gehen. Bewahren Sie die Originaldatei auf, wenn Leser klickbare Links brauchen.

Nein, das Ergebnis ist reines Bild, und das Tool führt keine OCR durch. Verlangt ein Gericht oder eine Behörde ein durchsuchbares PDF, reichen Sie das native PDF ein oder lassen Sie separat OCR in einer PDF-Software für den Desktop laufen.

Text im Original wird als kompakte Vektordaten gespeichert, während die gescannte Kopie jede Seite als JPEG-Bild speichert. Senken Sie die Auflösung von 2× auf 1,5×, oder nutzen Sie weniger Seiten pro Datei, um die Größe zu verringern.
