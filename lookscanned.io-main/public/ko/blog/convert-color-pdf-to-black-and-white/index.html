PDF 흑백 변환: 컬러 PDF를 흑백으로 바꾸는 무료 방법 5가지

📅 2026년 9월 ⏱ 읽는 시간 23분 ✍ Make PDF look scanned 팀

컬러 PDF 흑백 변환은 무료 브라우저 도구에서 색 공간을 회색조로 두고 노이즈, 흐림, 회전을 0으로 맞춘 뒤 다운로드하면 끝납니다. 맥에서는 미리보기의 파일 > 내보내기에서 Quartz 필터를 적용하고, 윈도우에서는 회색조 옵션을 켜고 인쇄하면 됩니다. 회색조는 256단계의 회색을, 순수 흑백은 두 가지 톤만 남깁니다.

컬러 PDF가 오히려 맞지 않는 경우가 많습니다. 인쇄 비용이 많이 들고, 법원이나 학교 포털에 올릴 때 업로드가 느리며, 서류 양식에서 흑백 사본을 요구하기도 합니다. 이 가이드에서는 무료로 PDF 흑백 변환을 하는 5가지 방법과 각 방법이 텍스트와 파일 용량에 미치는 영향, 그리고 회색조가 정보를 가리는 경우를 차례로 설명합니다.

제품 관련 사실은 저희 도구에서 직접 확인한 내용이며, 나머지는 Apple과 Microsoft 지원 페이지, 미국 연방 디지털화 가이드라인, 미국 법원, 대학 도서관 자료에서 가져왔습니다. 출처는 모두 본문에 링크로 달았습니다.

컬러 PDF를 흑백으로 변환하는 방법

컬러 PDF를 흑백으로 변환하려면 모든 페이지를 색 정보 없이 다시 렌더링해야 합니다. 브라우저 도구, 맥의 미리보기, 인쇄 대화상자, 실제 프린터 중 어느 것으로도 할 수 있습니다. 무료로 가장 빠른 방법은 브라우저에서 회색조로 변환하는 것으로, 설치나 계정 없이 몇 초면 끝납니다.

아래에서 소개하는 5가지 방법은 실제로 세 가지 면에서 차이가 납니다. 텍스트를 계속 선택할 수 있는지, 결과가 두 가지 톤의 순수 흑백인지 회색조인지, 파일 용량이 얼마나 되는지입니다. 습관이 아니라 받는 쪽에서 필요로 하는 것을 기준으로 방법을 고르세요.

  • 브라우저 도구(모든 OS): 회색조 페이지, 파일이 기기 밖으로 나가지 않음, 첫 로드 후 오프라인에서 작동. 단, 페이지가 이미지로 바뀝니다.
  • 맥 미리보기: 내보낼 때 Quartz 필터를 적용합니다. 모든 맥에 기본으로 들어 있습니다.
  • 윈도우 인쇄 대화상자: 프린터 드라이버나 앱이 지원하면 회색조로 저장됩니다.
  • Chrome 또는 Edge 인쇄 대화상자: 선택한 대상이 지원하면 색상 설정을 쓸 수 있습니다.
  • 인쇄 후 스캔: 실제 종이에 회색조로 인쇄한 뒤 다시 스캔해 PDF로 만듭니다.
시간이 없나요?스캐너를 열고 PDF를 끌어다 놓은 뒤, 색 공간은 회색조 그대로 두고 노이즈, 흐림, 회전을 0으로 옮긴 다음 다운로드를 클릭하세요. 원래 레이아웃 그대로 깔끔한 회색조 PDF를 받을 수 있습니다.

회색조 PDF와 흑백 PDF는 무엇이 다른가요?

회색조(그레이스케일) PDF는 각 픽셀을 여러 단계의 회색 중 하나로 저장하며, 8비트라면 보통 256단계입니다. 순수 흑백 PDF는 이진 또는 1비트라고도 하며, 각 픽셀을 완전한 검정이나 완전한 흰색 중 하나로만 저장합니다. "흑백"을 요청하는 사람 대부분은 사진과 음영이 잘 보이는 회색조를 원합니다.

FADGI(미국 연방기관 디지털화 가이드라인)는 문화유산 자료 디지털화 기술 가이드라인에서 두 용어를 정확히 정의합니다. "이진(Bitonal): 검정과 흰색, 두 가지 색만 사용해 만든 디지털 이미지." 그리고 "회색조(Grayscale): 흰색과 검정 사이의 다양한 회색을 사용해 만든 디지털 이미지."

차이는 비트 심도를 보면 숫자로 분명해집니다. 위키백과의 이진 이미지 항목에 따르면 2단계 이미지는 픽셀 하나를 1비트로 저장합니다. 8비트 회색조 픽셀은 256가지 값을 가질 수 있으며, 이미지 스캐너의 역사에 따르면 256단계의 회색을 뜻하는 8비트 스캔은 1989년에 데스크톱 스캐너에 도입되었습니다.

컬러, 회색조, 이진 PDF 페이지 비교
페이지 유형픽셀당 비트픽셀당 톤 수적합한 용도
컬러(RGB)24약 1,670만 색사진, 차트, 컬러 도장
회색조8회색 256단계텍스트와 이미지가 섞인 문서, 인쇄, 대부분의 "흑백" 요청
이진(순수 흑백)12(검정 또는 흰색)텍스트만 있는 문서, 법원 전자 제출, 팩스 같은 사본

24비트 컬러 픽셀은 빨강, 초록, 파랑 채널에 각각 8비트씩 할당된 것입니다. 그래서 미국 연방 기록물 디지털화 규정(36 CFR 1236)에서도 일반적인 컬러 스캔을 24비트로 설명합니다. 회색조는 이 가운데 두 채널을 버립니다. 이진은 한발 더 나아가 모든 회색 톤을 버리기 때문에 가는 회색 선, 연필 자국, 사진의 세부가 사라지거나 자잘한 점으로 바뀔 수 있습니다.

정리하면, PDF에 사진, 로고, 차트, 흐린 서명이 있다면 회색조를 선택하세요. 입력된 텍스트만 있고 받는 쪽에서 가능한 한 작은 파일을 요구한다면 이진도 괜찮지만, 변환한 뒤에는 모든 페이지를 확인하세요.

방법 1: 브라우저에서 PDF 흑백 변환하기

무료 브라우저 도구는 모든 페이지를 회색조로 렌더링해 새 PDF에 담는 방식으로 컬러 PDF를 흑백으로 변환합니다. 작업은 pdf.js와 canvas로 로컬에서 이루어지므로 파일이 처리용 서버에 업로드되지 않습니다. 윈도우, 맥, ChromeOS, 리눅스와 모바일 브라우저에서 작동합니다.

이 도구는 원래 PDF를 스캔한 것처럼 만들기 위해 만들어졌기 때문에 기본 출력에 약한 노이즈, 흐림, 살짝 기울어진 각도가 더해집니다. 이 효과를 모두 0으로 두면 같은 엔진이 깔끔한 회색조 변환기가 됩니다. 사무실 복사기에서 막 나온 것 같은 사본을 원한다면 반대로 기본값을 그대로 두세요.

  1. 도구를 엽니다. Chrome, Edge, Safari, Firefox에서 pdflookscanned.com/scan에 접속하세요. 회원가입은 필요 없으며, 처음 한 번 로드한 뒤에는 오프라인에서도 작동합니다.
  2. 컬러 PDF를 추가합니다. 파일을 페이지로 끌어다 놓거나 클릭해서 선택하세요. 몇 초 안에 첫 페이지의 실시간 미리보기가 나타납니다.
  3. 색 공간을 회색조로 둡니다. 회색조가 기본값이므로 새로 열면 이미 회색조 PDF가 만들어집니다. 원래 색을 유지하고 싶을 때만 컬러로 바꾸세요.
  4. 스캔 효과를 없앱니다. 노이즈 0, 흐림 0, 회전 0°, 회전 편차 0°로 설정하세요. 누런 톤은 0, 테두리는 아니요로 두면 흰 바탕에 중립적인 회색만 남습니다.
  5. 필요하면 대비를 조정합니다. 대비와 밝기는 0~2 범위이며 1이 중립입니다. 흐린 컬러 글자가 회색조에서 옅어진다면 대비를 1.2~1.4 정도로 올리세요.
  6. 해상도를 고릅니다. 2×(약 144 dpi)는 화면으로 읽거나 대부분의 업로드에 적합합니다. 글자가 작거나 인쇄할 문서라면 3×(약 216 dpi)를 쓰세요.
  7. PDF를 다운로드합니다. 다운로드를 클릭한 뒤 결과 파일을 열어, 보내기 전에 모든 페이지를 훑어보세요.

여러 파일을 한꺼번에 처리하려면 일괄 스캔에서 같은 설정을 여러 PDF에 적용해 ZIP 파일 하나로 받을 수 있습니다. 파일을 자주 변환한다면 같은 엔진을 측면 패널에서 쓰는 Chrome 확장 프로그램도 있습니다.

파일에서 달라지는 점이 도구는 각 페이지를 래스터화합니다. 텍스트, 벡터 선, 이미지가 페이지마다 회색조 JPEG 이미지 한 장이 되어 새 PDF에 들어갑니다. 보기에는 문제가 없지만 텍스트를 더 이상 선택하거나 검색할 수 없습니다. 살아 있는 텍스트가 필요하다면 아래의 미리보기나 인쇄 방법을 쓰거나, 검색용으로 컬러 원본을 보관하세요.

깔끔한 회색조 PDF를 만드는 설정은?

깔끔한 회색조 PDF는 색 공간을 회색조로 두고 모든 스캔 효과를 0으로 맞추면 만들어집니다. 노이즈 0, 흐림 0, 회전 0°, 회전 편차 0°, 누런 톤 0, 테두리 아니요입니다. 흐린 글자를 보정할 필요가 없다면 밝기와 대비는 1로 둡니다. 해상도는 용량과 선명도의 균형이 좋은 기본값 2×를 권합니다.

색 공간
회색조(기본값). 1비트 이진 페이지가 아니라 회색조 페이지를 만듭니다.
노이즈
깔끔한 사본은 0. 기본값 0.1은 약한 스캐너 입자감을 더합니다.
흐림
선명한 글자는 0. 기본값 0.3은 평판 스캐너처럼 윤곽을 부드럽게 합니다.
회전 / 회전 편차
곧은 페이지는 0°와 0°. 기본값은 1°와 0.5°입니다.
밝기
1이 중립이며 범위는 0~2입니다. 회색 배경을 하얗게 하려면 살짝 올리세요.
대비
1이 중립이며 범위는 0~2입니다. 옅은 컬러 글자를 진하게 하려면 1.2~1.4로 올리세요.
누런 톤
0이면 흰 종이 그대로입니다. 값을 높이면 따뜻한 종이 색감이 더해집니다.
해상도
1×~3×, 0.5 단위. 2× ≈ 144 dpi, 3× ≈ 216 dpi.

반대로 복사본 느낌을 원한다면 기본값을 그대로 두세요. 회색조, 노이즈 0.1, 흐림 0.3, 회전 1°, 회전 편차 0.5°입니다. 흑백으로 인쇄한 뒤 스캔한 것 같은 PDF를 원할 때 대부분 이 설정을 떠올립니다. 각 아티팩트와 프리셋은 스캔 효과 설정 가이드에서 자세히 설명합니다.

이 도구로는 엄밀한 1비트 파일을 만들 수 없습니다. 대비를 높게(1.6~2 정도) 올리면 페이지가 강한 두 톤처럼 보이지만, 픽셀은 여전히 회색조 JPEG로 저장됩니다. 포털에서 이진 이미지를 명시적으로 요구한다면 방법 5에서 설명하듯 스캐너를 흑백 모드로 설정해 스캔하세요.

방법 2: 맥에서 컬러 PDF를 흑백으로 변환하기

맥에서는 기본 PDF 뷰어인 미리보기로 컬러 PDF를 흑백으로 변환합니다. 파일을 열고 파일 > 내보내기를 선택한 뒤 흑백이나 회색 톤 같은 Quartz 필터를 골라 새 이름으로 저장하면 됩니다. 따로 내려받을 앱이 없고, 내보내기는 몇 초면 끝납니다.

Apple은 미리보기 사용 설명서에서 이렇게 직접 설명합니다. "미리보기에서 연 PDF는 효과를 추가하거나 색상을 바꾸는 Quartz 필터로 수정할 수 있습니다. 예를 들어 컬러 문서를 흑백으로 변환하거나 세피아 톤을 적용할 수 있습니다."

  1. 미리보기에서 컬러 PDF를 엽니다(파일을 이중 클릭하거나, 오른쪽 클릭 > 다음으로 열기 > 미리보기).
  2. 파일 > 내보내기를 선택합니다. PDF로 내보내기는 쓰지 마세요. 그 대화상자에는 Quartz 필터 메뉴가 없습니다.
  3. 포맷이 PDF로 되어 있는지 확인합니다.
  4. Quartz 필터 팝업 메뉴를 열고 흑백 또는 회색 톤을 선택합니다.
  5. 컬러 원본이 남도록 "invoice-bw.pdf"처럼 새 이름을 입력한 뒤 저장을 클릭합니다.

미리보기에서 흑백과 회색 톤 중 무엇을 고를까요?

미리보기의 두 필터 모두 색을 없애지만 톤을 표현하는 방식이 다릅니다. 흑백은 대비가 강하고 딱딱한 페이지를 만들어 옅은 색이 빠질 수 있고, 회색 톤은 사진과 차트에 어울리는 부드러운 회색을 유지합니다. 문서에 컬러 그래픽이 있다면 두 필터로 한 번씩 내보내 나란히 비교해 보세요.

필터는 페이지를 사진처럼 찍는 것이 아니라 PDF를 내보내는 과정에서 적용되므로, 입력된 텍스트는 대개 그대로 선택하고 검색할 수 있습니다. 화면에 보이는 단어를 Command-F로 검색해 확인하세요. 미리보기에는 파일 크기 줄이기 필터도 있지만, Apple의 PDF 크기 줄이기 안내 페이지에 따르면 품질이 떨어질 수 있으므로 회색조 결과를 먼저 확인한 뒤에 적용하세요.

방법 3: 윈도우에서 PDF 흑백 변환하기

윈도우에서는 기본 제공되는 Microsoft Print to PDF 프린터로 회색조나 흑백 옵션을 켜고 인쇄해 PDF 흑백 변환을 합니다. 문제는 이 옵션이 앱이나 프린터 드라이버가 지원할 때만 나타난다는 점입니다. 그래서 환경에 따라서는 그대로 컬러로 인쇄되기도 합니다.

Microsoft는 워드에서 흑백으로 인쇄하기 도움말에서 파일 > 인쇄 > 프린터 속성을 열고 "컬러, 회색조 또는 흑백으로 인쇄하기 위한 속성을 선택"하라고 안내합니다. 같은 페이지는 사용할 수 있는 설정이 프린터 모델과 드라이버에 따라 다르다고 덧붙입니다.

  1. 평소 PDF를 볼 때 쓰는 앱에서 파일을 열거나, 원본 문서(워드, 엑셀)가 남아 있다면 그 문서를 엽니다.
  2. Ctrl+P를 누르고 프린터로 Microsoft Print to PDF를 선택합니다.
  3. 대화상자에서 색, 컬러 모드, 회색조 같은 설정을 찾거나, 프린터 속성(기본 설정)을 클릭해 그 안을 확인합니다.
  4. 흑백 또는 회색조를 선택하고 인쇄를 클릭한 뒤, 저장 위치를 묻는 창에서 새 PDF의 이름을 입력합니다.
  5. 저장된 파일을 열어 색이 정말 없어졌는지 확인합니다.
회색조 옵션이 없다면Microsoft Print to PDF는 기본적인 드라이버라서 많은 PC에서 속성에 방향과 용지 크기만 표시됩니다. 색 설정이 보이지 않으면 결과물은 컬러 그대로 남습니다. 이럴 때는 방법 4의 Edge 인쇄 대화상자나 방법 1의 브라우저 도구를 쓰세요.

인쇄 방법이 통하면 앱이 그린 텍스트는 대개 텍스트로 유지되므로 흑백 PDF에서도 검색할 수 있습니다. 워드 파일에서 시작했다면 PDF 뷰어보다 워드에서 직접 인쇄하는 편이 레이아웃이 더 잘 유지됩니다.

방법 4: Chrome이나 Edge에서 흑백 PDF 저장하기

Chrome과 Edge는 PDF를 열어 다시 인쇄할 수 있으며, 인쇄 미리보기에는 지원되는 대상에 한해 색상 설정이 있습니다. 설정이 보이면 흑백을 선택한 뒤 저장하거나 인쇄하세요. PDF 대상에서 색상 옵션이 나타나는지는 브라우저 버전과 선택한 프린터에 따라 다릅니다.

Microsoft의 Edge 인쇄 가이드에는 Edge 인쇄 대화상자의 색 설정에 컬러와 흑백 옵션이 있다고 나와 있습니다. Chrome의 인쇄 미리보기도 여러 프린터에서 비슷한 색상 메뉴를 제공합니다. 하지만 기본 대상인 PDF로 저장에서는 색상 메뉴가 없는 경우가 많고, 그러면 아무것도 변환되지 않습니다.

  1. 컬러 PDF를 Chrome이나 Edge 창으로 끌어다 놓아 내장 뷰어에서 엽니다.
  2. Ctrl+P(맥에서는 Command-P)를 눌러 인쇄 미리보기를 엽니다.
  3. 대상을 고릅니다. PDF로 저장 또는 윈도우의 Microsoft Print to PDF를 선택하세요.
  4. 필요하면 설정 더보기를 열어 색상 항목을 찾습니다. 있다면 흑백을 선택하고 미리보기가 회색으로 바뀌는지 확인하세요.
  5. 미리보기가 계속 컬러라면 그 대상은 전환을 지원하지 않는 것이니 다른 방법을 쓰세요.
  6. 저장 또는 인쇄를 클릭하고 새 파일의 이름을 정합니다.

판단 기준은 미리보기 화면입니다. 저장하기 전에 회색으로 바뀌면 저장된 PDF도 회색입니다. 브라우저 인쇄는 페이지를 다시 구성하기 때문에 원본의 양식 필드, 링크, 책갈피가 남지 않을 수 있습니다. 이런 요소가 중요하다면 컬러 원본을 보관하세요.

방법 5: 회색조로 인쇄한 뒤 흑백 PDF로 스캔하기

가장 고전적인 방법은 컬러 PDF를 실제 프린터에서 회색조로 인쇄하고, 스캐너를 흑백이나 회색조 모드로 설정해 그 종이를 다시 스캔하는 것입니다. 느리고 종이와 토너가 들지만, 진짜 1비트 이진 스캔을 만들 수 있는 유일한 방법입니다.

스캐너와 복합기는 보통 컬러, 회색조, 흑백(텍스트나 단색으로 표시되기도 함)의 세 가지 색 모드를 제공합니다. 이 중 흑백 모드가 법원 시스템에서 요구하는 이진 설정입니다.

미국 노스캐롤라이나 중부 연방지방법원은 CM/ECF 절차 매뉴얼에서 그 이유를 이렇게 설명합니다. "컬러로 스캔했거나 그래픽이 포함된 문서는 업로드 시간이 훨씬 오래 걸리므로, 제출 당사자는 스캐너를 컬러가 아닌 흑백, 300 dpi로 스캔하도록 설정해야 합니다."

  1. 프린터의 회색조 또는 흑백 옵션을 켜고 PDF를 인쇄합니다.
  2. 인쇄한 종이를 스캐너나 자동 급지 장치(ADF)에 넣습니다.
  3. 색 모드(입력된 텍스트는 흑백, 사진은 회색조)와 300 dpi를 설정합니다.
  4. PDF로 스캔한 뒤 페이지마다 기울어짐, 잘린 가장자리, 흐린 부분이 없는지 확인합니다.

이렇게 만든 PDF는 종이를 찍은 이미지이므로 스캐너 소프트웨어가 OCR(광학 문자 인식)을 실행하지 않는 한 텍스트를 검색할 수 없습니다. 또 살짝 기울어진 각도, 먼지, 고르지 않은 회색 같은 실제 스캐너의 흔적도 남습니다. 종이 없이 그런 느낌만 원한다면 PDF 스캔본 변환 가이드에서 디지털로 재현하는 방법을 확인하세요.

컬러 PDF 흑백 변환, 어떤 방법이 좋을까요?

컬러 PDF 흑백 변환에 가장 좋은 방법은 사용하는 시스템과 받는 쪽에서 필요로 하는 것에 따라 달라집니다. 브라우저 도구는 어디서나 작동하고 일정한 회색조 결과를 주며, 맥에서는 미리보기가 가장 빠릅니다. 인쇄 방법은 옵션이 있을 때 텍스트 검색을 유지하고, 인쇄 후 스캔은 진짜 이진 파일을 만드는 유일한 방법입니다.

간단한 기준은 이렇습니다. 검색 가능한 텍스트가 필요하면 방법 2, 3, 4부터 시도하세요. 어떤 기기에서든 매번 같은 결과가 나오는 확실한 방법이 필요하면 방법 1을 쓰세요. 포털에서 이진 이미지를 요구한다면 방법 5를 쓰세요.

회색조 PDF는 컬러 PDF보다 용량이 작나요?

회색조 PDF는 같은 페이지를 컬러로 저장할 때보다 대개 용량이 작고, 순수 흑백 PDF는 그보다 훨씬 더 작습니다. 픽셀 하나에 24비트 대신 8비트나 1비트만 담기 때문입니다. 다만 이미지보다 텍스트가 대부분인 PDF라면 회색조로 줄어드는 용량은 크지 않을 수 있습니다.

미국 캘리포니아 북부 연방지방법원은 CM/ECF 제출 준비 가이드에서 인상적인 비교 결과를 공개했습니다. 317페이지 문서를 300 ppi 이진으로 스캔하면 23.86 MB였고 글자도 잘 읽혔습니다. 같은 문서를 400 ppi 회색조로 스캔하면 374.47 MB로, 약 15.7배 컸습니다.

374.47 MB같은 페이지, 400 ppi 회색조 스캔 (N.D. Cal.)
~15.7×두 스캔의 용량 차이

이 차이를 만드는 요인은 비트 심도와 해상도 두 가지입니다. 법원의 회색조 버전은 해상도도 더 높았으므로 차이의 일부는 400 ppi와 300 ppi의 차이에서 옵니다. 그래도 결론은 같습니다. 이진 파일은 훨씬 작습니다. 그래서 미국 워싱턴 서부 연방지방법원도 CM/ECF 기술 FAQ에서 "높은 해상도로 스캔하면 업로드 중 지연이나 시간 초과 문제가 생길 수 있습니다"라고 경고합니다.

저희 도구에서는 색 모드보다 해상도가 더 중요합니다. 텍스트 PDF를 1×나 1.5×로 변환하면 3×보다 훨씬 작은 파일이 됩니다. 각 페이지가 JPEG 이미지로 저장되고, 픽셀 수는 배율의 제곱에 비례해 늘어나기 때문입니다. 원래 용량이 작은 디지털 PDF라면 이미지로 바꿨을 때 오히려 커질 수 있습니다.

흑백 PDF는 인쇄 비용이 더 적게 드나요?

페이지당 요금을 받는 곳이라면 흑백 PDF는 대개 인쇄 비용이 더 적게 듭니다. 대학 도서관들은 그 차이를 공개하고 있는데, 컬러 페이지는 흔히 흑백 요금의 약 2.5~3배입니다. 집에서는 프린터와 카트리지에 따라 절약되는 금액이 달라서 하나의 수치로 말할 수 없습니다.

PDF를 다른 사람이나 복사 가게, 공용 인쇄 대기열로 보낼 때는 프린터에서 "흑백"에 체크하는 것보다 파일 자체를 변환하는 편이 더 확실합니다. 인쇄할 색이 남아 있지 않으니 받는 쪽의 기본 설정이 어떻든 상관없습니다.

회색조 PDF에서 정보가 사라지는 경우는?

회색조 PDF는 의미가 색에 달려 있을 때 정보를 잃습니다. 형광펜 표시, 빨간 도장이나 수정 표시, 색으로 구분한 차트, 지도, 신호등 색으로 상태를 표시한 표가 그렇습니다. 빨강과 초록처럼 밝기가 비슷한 색은 거의 같은 회색이 되어, 변환 후에는 구분이 그냥 사라집니다.

문제는 색상이 아니라 밝기입니다. 회색조는 각 색이 얼마나 밝거나 어두운지만 남깁니다. 노란 형광펜은 아주 밝아서 흰 종이 속으로 사라지는 경우가 많고, 채도 높은 빨강과 중간 톤의 초록은 거의 같은 회색이 될 수 있으며, 파란 링크는 평범한 검은 글자처럼 보일 수 있습니다.

컬러 형광펜, 도장, 차트를 위한 대비 팁

  • 노란 형광펜: 도구에서 대비를 1.3 정도로 올리고 밝기를 살짝(0.9) 낮추면 형광펜 부분이 눈에 보이는 회색 띠로 남습니다.
  • 빨간 도장과 서명: 빨강은 중간 회색이 되기 쉽습니다. 대비를 높이고 미리보기를 확대해 도장 글자가 여전히 읽히는지 확인하세요.
  • 차트와 그래프: 데이터 계열이 색으로만 구분된다면 원본을 수정해 패턴, 마커, 직접 레이블을 추가하고, 새 PDF로 내보낸 다음 변환하세요.
  • 지도와 히트맵: 그라데이션은 회색조에서 거의 살아남지 못하므로 컬러 사본을 보관하거나 두 버전을 함께 보내세요.
  • 옅은 글자: 흰 바탕의 연회색이나 파스텔 톤 글자는 흐려질 수 있습니다. 대비를 1.2~1.4로 올리면 대개 다시 잘 보입니다.

이 원칙은 접근성의 핵심 원칙이기도 합니다. W3C의 색 사용에 관한 WCAG 지침은 색이 정보를 전달하는 유일한 시각적 수단이 되어서는 안 된다고 말합니다. 회색조 테스트는 문서가 이 원칙을 어기는 부분을 빠르게 찾아내는 방법입니다.

이진 변환은 더 가혹합니다. 모든 픽셀이 임계값에 따라 검정 또는 흰색이 되므로 옅은 음영, 회색 배경, 사진이 얼룩처럼 변하거나 사라질 수 있습니다. 포털에서 1비트 출력을 강제한다면 사진, 레터헤드 로고, 서명을 페이지마다 확인하세요.

보내기 전에 흑백 PDF를 확인하는 방법

흑백 PDF는 100% 배율로 열어 모든 페이지를 넘겨 보고, 화면에 보이는 단어를 검색하고, 페이지 수를 원본과 비교하고, 파일 용량을 확인하는 순서로 점검합니다. 5분만 확인해도 업로드가 반려되거나 도장이 읽히지 않는 서류를 보내는 일을 막을 수 있습니다.

  1. 페이지 수: 변환한 파일의 페이지 수가 원본과 정확히 같아야 합니다.
  2. 가독성: 가장 작은 글자, 각주, 서명을 100% 이상으로 확대해 보세요.
  3. 색에 의존하는 내용: 위 목록에 나온 형광펜 표시, 차트 범례, 도장을 하나하나 확인하세요.
  4. 검색 테스트: Ctrl+F 또는 Command-F를 누르고 화면에 보이는 단어를 검색하세요. 검색되면 텍스트가 살아 있는 것이고, 검색되지 않으면 브라우저 도구로 변환했을 때처럼 페이지가 이미지라는 뜻입니다. 그 차이는 스캔 PDF란 가이드에서 설명합니다.
  5. 파일 용량: 업로드한 뒤가 아니라 업로드하기 전에 포털의 용량 제한과 비교하세요.
정직하게 사용하세요흑백 변환이나 스캔 효과는 파일이 보이는 모습을 바꿀 뿐, 진위를 바꾸지는 않습니다. 공문서, 신분증, 본인의 것이 아닌 서명을 변조하거나 위조하는 데 사용하지 마세요. 일부 법원과 기관은 텍스트 검색이 가능한 PDF를 요구하므로 이미지로만 된 페이지는 받지 않습니다. 제출하기 전에 제출 규정을 확인하세요.

텍스트 검색 가능 여부는 제출 규정 이상의 의미가 있습니다. W3C의 PDF7 기법은 "텍스트를 스캔한 이미지로 이루어진 문서는 내용이 검색 가능한 텍스트가 아니라 이미지이기 때문에 본질적으로 접근할 수 없습니다"라고 명시합니다. 접근성이 필요하다면 텍스트를 유지하는 방법을 쓰거나, 이미지로만 된 결과물에 OCR을 실행하세요.

컬러 PDF를 흑백으로 변환하는 방법을 묻는 분들 대부분은 진짜 1비트 흑백이 아니라 회색조가 필요합니다. 화면에서 읽기 좋고 인쇄도 깔끔하게 되기 때문에 저희는 기본 색 공간을 회색조로 두고 있으며, 저희 도구가 페이지를 이미지로 바꾼다는 점도 분명히 알려 드립니다. 검색 가능한 텍스트가 필요하다면 미리보기나 인쇄 방법을, 어떤 기기에서든 같은 결과가 필요하다면 브라우저 도구를 쓰세요.

PDF 흑백 변환: 자주 묻는 질문

컬러 PDF를 흑백으로 변환할 때 사람들이 가장 많이 묻는 질문에 답합니다. 무료 방법, 휴대폰, 회색조와 이진 출력의 차이, 검색 가능한 텍스트, 파일 용량, 인쇄, 개인정보 보호를 다룹니다. 답은 짧게 정리했으며, 전체 단계와 출처는 위의 해당 섹션에서 확인할 수 있습니다.

컬러 PDF를 무료로 흑백으로 변환하려면 어떻게 하나요?

무료 브라우저 도구를 열고 색 공간은 회색조로 둔 채 노이즈, 흐림, 회전을 0으로 맞춘 뒤 결과를 다운로드하세요. 맥에서는 미리보기의 파일 > 내보내기에서 Quartz 필터를 쓰는 방법도 무료입니다. 윈도우에서는 드라이버가 회색조 옵션을 지원하면 인쇄 대화상자로도 변환할 수 있습니다.

회색조와 흑백은 같은 건가요?

아닙니다. 회색조는 8비트로 픽셀마다 최대 256단계의 회색을 저장하고, 순수 흑백(이진)은 1비트로 검정이나 흰색만 저장합니다. 일상적으로 "흑백 PDF"라고 하면 보통 사진과 음영이 잘 보이는 회색조를 뜻합니다.

변환한 뒤에도 텍스트를 검색할 수 있나요?

미리보기와 대부분의 PDF 인쇄 방법에서는 입력된 텍스트를 대개 그대로 선택하고 검색할 수 있습니다. 저희 브라우저 도구는 페이지를 래스터화하므로 텍스트가 이미지의 일부가 되어 더 이상 검색하거나 복사할 수 없습니다. 결과물은 Ctrl+F나 Command-F로 확인하세요.

맥에서 PDF를 회색조로 변환하려면 어떻게 하나요?

미리보기에서 PDF를 열고 파일 > 내보내기를 선택한 뒤 Quartz 필터 메뉴에서 회색 톤이나 흑백을 골라 새 이름으로 저장하세요. 회색 톤은 음영을 부드럽게 유지하고, 흑백은 대비가 더 강합니다.

Microsoft Print to PDF로 인쇄하면 왜 색이 그대로 남나요?

회색조 옵션은 앱과 프린터 드라이버에 따라 달라지는데, Microsoft Print to PDF는 방향과 용지 크기만 표시하는 경우가 많습니다. 색 설정이 없으면 결과물은 컬러로 남습니다. 대신 Edge 인쇄 대화상자나 브라우저 도구를 쓰세요.

휴대폰에서도 컬러 PDF를 흑백으로 변환할 수 있나요?

네. 저희 도구의 웹사이트 버전은 아이폰과 안드로이드의 모바일 브라우저에서 작동하며, 처리는 휴대폰 안에서 이루어집니다. 스캔 페이지를 열고 파일 앱에서 PDF를 선택한 뒤 회색조를 그대로 두고 변환된 사본을 다운로드하세요.

흑백으로 변환하면 PDF 파일 용량이 줄어드나요?

줄어드는 경우가 많지만 항상 그렇지는 않습니다. 이진 스캔은 회색조 스캔보다 훨씬 작습니다. 캘리포니아 북부 연방지방법원의 테스트에서는 같은 317페이지가 23.86 MB 대 374.47 MB로 측정되었습니다. 디지털 텍스트 PDF를 페이지 이미지로 바꾸면 오히려 커질 수 있으니 변환한 뒤 용량을 비교하세요.

브라우저 도구로 진짜 1비트 흑백을 만들 수 있나요?

아니요. 이 도구는 회색조 JPEG 페이지를 출력합니다. 대비 값을 높이면 페이지가 강한 두 톤처럼 보이지만 픽셀은 여전히 회색조입니다. 진짜 이진 파일이 필요하다면 스캐너의 흑백 모드로 종이를 스캔하세요.

노란 형광펜 표시가 왜 사라졌나요?

회색조는 밝기만 남기는데, 노랑은 흰 종이만큼이나 밝아서 형광펜 표시가 옅어져 사라집니다. 대비를 1.3 정도로 올리고 밝기를 살짝 낮추거나, 변환하기 전에 중요한 부분을 밑줄로 다시 표시하세요.

브라우저 도구를 쓰면 PDF가 업로드되나요?

아니요. 페이지는 pdf.js와 canvas로 브라우저에서 로컬로 렌더링되고 변환되며, 파일은 처리용 서버로 전송되지 않습니다. 처음 방문한 뒤에는 오프라인에서도 작동합니다.

흑백 PDF를 스캔한 것처럼 보이게 할 수도 있나요?

네. 색 공간을 회색조로 두고 기본값인 노이즈 0.1, 흐림 0.3, 회전 1°를 그대로 두면 복사기로 복사한 듯한 결과가 나옵니다. 6가지 방법과 프리셋은 PDF 스캔한 것처럼 만드는 방법 가이드에서 비교합니다.

여러 컬러 PDF를 한 번에 흑백으로 변환하려면 어떻게 하나요?

일괄 스캔을 사용하세요. 여러 PDF를 추가하고 회색조와 스캔 효과 0을 적용한 뒤, 변환된 파일을 모두 ZIP 파일 하나로 다운로드하면 됩니다. Chrome 확장 프로그램에서도 여러 파일을 한 번에 불러올 수 있습니다.
