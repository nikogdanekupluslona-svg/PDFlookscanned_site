PDF를 스캔한 것처럼 만드는 가장 빠른 방법은?

PDF를 스캔한 것처럼 만드는 가장 빠른 방법은 브라우저 기반 스캔 효과 도구입니다. 페이지를 열고 PDF를 끌어다 놓은 뒤 기본 회전, 흐림, 노이즈 값을 그대로 두거나 조정하고 결과를 다운로드하면 됩니다. 파일 하나당 1분이 채 걸리지 않고 비용도 들지 않습니다.

나머지 5가지 방법은 속도를 포기하는 대신 더 세밀한 제어나 실제 종이의 사실감을 얻습니다. 인쇄 대화상자는 빠르지만 절반쯤만 그럴듯합니다. 래스터 이미지 편집기는 모든 것을 직접 제어할 수 있지만 10~30분이 걸립니다. 휴대폰 촬영이나 실제 프린터와 스캐너는 진짜 스캔 흔적을 남기지만 종이, 시간, 장비가 필요합니다. 아래 표에서 6가지 방법을 한눈에 비교해 보세요.

방법 1: 브라우저에서 PDF를 스캔한 것처럼 만들기

Make PDF look scanned 웹 도구는 브라우저 안에서 PDF의 모든 페이지를 이미지로 렌더링하고, 회전, 흐림, 노이즈, 밝기, 대비, 종이 색감을 적용한 뒤 그 이미지를 새 PDF로 저장합니다. 파일은 기기 밖으로 나가지 않으며, 도구는 무료이고 회원가입도 필요 없습니다.

이 도구는 내부적으로 PDF.js를 사용해 각 페이지를 HTML 캔버스에 그립니다. Mozilla는 PDF.js를 "PDF를 파싱하고 렌더링하기 위한 웹 표준 기반의 범용 플랫폼"이라고 설명합니다. 처리가 로컬에서 이루어지므로 처음 한 번 로드한 뒤에는 오프라인에서도 작동하고, 모바일 브라우저에서도 실행됩니다.

브라우저 도구로 PDF를 스캔한 것처럼 만드는 단계

  1. 스캐너를 엽니다. Chrome, Edge, Safari, Firefox에서 무료 스캔 도구로 이동하세요. 계정도 설치도 필요 없습니다.
  2. PDF를 추가합니다. 파일을 페이지로 끌어다 놓거나 클릭해서 선택하세요. JPG, PNG, WebP, SVG, GIF, BMP, DOCX, XLSX, CSV, TXT, MD, HTML 파일도 넣을 수 있습니다.
  3. 실시간 미리보기를 확인합니다. 첫 페이지에 기본 효과가 이미 적용되어 나타납니다. 회전 1°, 무작위 편차 0.5°, 흐림 0.3, 노이즈 0.1, 회색조, 해상도 2×입니다.
  4. 기울기를 정합니다. 그럴듯한 사무실 스캔을 원한다면 회전을 0.5°~1.5° 사이로 두세요. 회전 편차는 0.5°~1°로 두면 손으로 한 장씩 넣었을 때처럼 페이지마다 각도가 조금씩 달라집니다.
  5. 흐림과 노이즈를 조정합니다. 흐림 0.2~0.4는 칼같이 날카로운 벡터 윤곽을 부드럽게 하고, 노이즈 0.1~0.25는 센서의 자잘한 점을 더합니다. 결정하기 전에 미리보기를 100%로 확대해 보세요.
  6. 색 공간과 종이 색감을 고릅니다. 계약서와 편지에는 회색조가 어울립니다. 도장, 로고, 컬러 양식이 있다면 컬러를 선택하고, 미색 종이 느낌을 원하면 누런 톤을 0.2~0.6으로 올리세요.
  7. 해상도를 선택합니다. 2×(약 144 dpi)는 균형 잡힌 기본값이고, 3×(약 216 dpi)는 더 선명하지만 파일 용량이 커집니다.
  8. 다운로드합니다. 다운로드 버튼을 클릭해 새 PDF를 저장하세요. 한 번 열어서 모든 페이지가 처리되었는지 확인합니다.

스캔 도구의 각 슬라이더는 무슨 역할을 하나요?

각 컨트롤은 실제 스캐너의 물리적 결함 하나에 대응합니다. 아래 범위와 기본값은 도구에서 그대로 가져온 것이므로, 이 가이드의 설정 조합을 그대로 재현할 수 있습니다.

회전(−10°~10°, 기본값 1°)
모든 페이지를 같은 각도로 기울여, 원고대 가장자리에서 살짝 비뚤게 놓인 종이를 흉내 냅니다.
회전 편차(0~10°, 기본값 0.5°)
페이지마다 무작위로 기울기를 더해, 여러 페이지 문서가 지나치게 똑같아 보이지 않게 합니다.
흐림(0~1, 기본값 0.3)
스캐너 광학계와 JPEG 압축처럼 윤곽을 부드럽게 만듭니다.
노이즈(0~1, 기본값 0.1)
센서 노이즈와 종이 질감 같은 무작위 점을 더합니다.
밝기와 대비(0~2, 기본값 1)
밝기를 올리면 종이가 희뿌옇게 바래고, 대비를 올리면 복사본 느낌이 납니다.
누런 톤(0~2, 기본값 0)
옅은 미색부터 누렇게 바랜 종이까지 따뜻한 세피아 색조를 입히며, 회색조와 컬러 모드 모두에서 작동합니다.
색 공간(회색조 또는 컬러, 기본값 회색조)
회색조는 일반적인 사무실 흑백 스캔을 흉내 냅니다.
테두리(예 또는 아니요, 기본값 아니요)
일부 스캐너에 찍히는 가장자리 선처럼 1픽셀 두께의 어두운 테두리를 그립니다.
해상도(1×~3×, 0.5 단위, 기본값 2×)
PDF 페이지는 인치당 72포인트로 배치되므로 1×는 72 dpi, 2×는 약 144 dpi, 3×는 약 216 dpi입니다.

72 dpi라는 기준은 임의로 정한 값이 아닙니다. PDF와 PostScript의 페이지 좌표계는 인치당 72포인트라는 타이포그래피 관례를 따르므로, 배율을 보면 각 페이지 이미지의 실질적인 스캔 해상도를 알 수 있습니다.

추가 기능: 워터마크, 도장, 메타데이터

스캔 효과 외에도 이 도구는 텍스트 또는 이미지 워터마크를 넣고, 가로·세로 위치와 크기를 조절할 수 있는 도장이나 서명 이미지를 추가하고, PDF 메타데이터 항목인 제목, 작성자, 주제, 키워드, 제작 프로그램, 작성 프로그램을 편집할 수 있습니다. 서명 이미지는 본인의 서명일 때만 사용하세요.

여러 PDF 파일을 한 번에 스캔한 것처럼 만드는 방법

여러 파일을 처리하려면 일괄 스캔을 열고 파일을 모두 추가한 뒤 효과를 한 번만 설정하고, 전체를 ZIP 파일 하나로 다운로드하세요. 입력한 파일마다 스캔 PDF가 따로 만들어지므로 청구서 10개를 넣으면 스캔 PDF 10개가 나옵니다.

워드, 엑셀, 구글 문서 파일이라면 먼저 PDF로 내보내세요이 도구는 PDF를 레이아웃 그대로 읽지만, DOCX에서는 원본 텍스트만 추출해 A4 페이지에 Helvetica 11 pt로 다시 조판하므로 글꼴, 표, 이미지가 사라집니다. 스프레드시트는 CSV 텍스트가 됩니다. 레이아웃이 중요하다면 먼저 PDF로 저장한 뒤(구글 문서: 파일 > 다운로드 > PDF 문서(.pdf)) 그 PDF를 스캔하세요. 자세한 내용은 워드·구글 문서를 스캔한 것처럼 만드는 가이드에서 확인할 수 있습니다.

방법 2: Chrome에서 PDF를 스캔본처럼 만들기

Make PDF look scanned Chrome 확장 프로그램은 같은 스캔 엔진을 브라우저 측면 패널에 넣어 두어, 새 탭을 열지 않고도 PDF를 스캔본처럼 만들 수 있게 해 줍니다. 파일은 로컬에서 처리되고, 여러 파일을 한 번에 처리해 ZIP 파일 하나로 함께 다운로드할 수 있습니다.

매주 문서를 변환하거나, 이메일이나 문서 제출 포털 같은 웹 앱에서 작업하다가 PDF 파일을 스캔한 것처럼 만들어야 할 일이 잦다면 확장 프로그램이 더 낫습니다. 측면 패널이 페이지 옆에 열려 있으므로 작업하던 위치를 잃지 않고 파일을 넣고, 효과를 조정하고, 다운로드할 수 있습니다.

  1. 확장 프로그램을 설치합니다. 별점 5점을 받은 Chrome 웹 스토어의 Make PDF look scanned 페이지를 열고 Chrome에 추가를 클릭하세요.
  2. 고정합니다. 도구 모음의 퍼즐 조각 아이콘을 클릭하고 확장 프로그램을 고정하면 클릭 한 번으로 열 수 있습니다.
  3. 측면 패널을 엽니다. 확장 프로그램 아이콘을 클릭하면 브라우저 창 오른쪽 패널에 스캐너가 열립니다.
  4. 파일을 하나 또는 여러 개 추가합니다. PDF나 이미지를 패널에 끌어다 놓으세요. 웹 도구와 같은 파일 형식과 슬라이더를 쓸 수 있습니다.
  5. 조정하고 다운로드합니다. 회전, 흐림, 노이즈, 색 공간을 설정한 뒤 스캔 PDF 하나를 다운로드하거나, 파일이 여러 개라면 ZIP 파일 하나로 받으세요.

Microsoft Edge 같은 Chromium 기반 브라우저도 대개 Chrome 웹 스토어에서 확장 프로그램을 설치할 수 있지만, 측면 패널 사용 환경은 Google Chrome을 기준으로 설계하고 테스트했습니다. 회사 컴퓨터에 확장 프로그램을 설치할 수 없다면 브라우저용 도구를 쓰세요. 설치할 것 없이 똑같은 결과를 얻을 수 있습니다.

방법 3: 인쇄 대화상자로도 스캔한 것처럼 될까요?

윈도우와 macOS에 내장된 인쇄 대화상자로는 PDF를 스캔한 것처럼 만드는 작업을 일부만 할 수 있습니다. Microsoft Print to PDF와 macOS 미리보기 앱은 페이지를 회색조로 바꾸거나 압축할 수 있지만 기울기, 흐림, 노이즈는 더하지 못하므로, 결과물은 스캔본이 아니라 회색 디지털 파일로 보입니다.

운영체제 기능만으로 PDF 문서를 스캔한 것처럼 만드는 방법을 찾고 있다면 이 경로를 알아 두세요.

그래도 인쇄 경로가 가장 유용한 경우는 두 가지입니다. 웹 도구를 전혀 쓸 수 없을 때, 그리고 준비 단계로 쓸 때입니다. 워드, 엑셀 문서나 웹 페이지를 먼저 PDF로 인쇄하면 레이아웃이 그대로 유지되고, 그 PDF에 완전한 스캔 효과를 적용할 수 있습니다.

윈도우: Microsoft Print to PDF

윈도우에는 모든 앱의 프린터 목록에 나타나는 "Microsoft Print to PDF"라는 가상 프린터가 들어 있습니다. PDF를 열고 Ctrl+P를 누른 뒤 Microsoft Print to PDF를 선택하고, 뷰어에서 지원한다면 색을 흑백 또는 회색조로 설정한 다음 새 파일을 저장하세요.

일부 PDF 뷰어에는 고급 인쇄 설정에 "이미지로 인쇄" 옵션도 있습니다. 이 옵션을 켜면 각 페이지가 래스터화되어, 처음부터 디지털로 만든 파일임을 드러내는 대표적인 흔적인 선택 가능한 텍스트가 사라집니다. 하지만 페이지는 여전히 반듯하고 완벽하게 깨끗합니다.

macOS: 미리보기 앱의 내보내기와 Quartz 필터

맥에서는 파일 > 프린트… > PDF > PDF로 저장을 거쳐 인쇄할 수 있는 모든 앱에서 PDF를 저장할 수 있습니다. 스캔 같은 색조를 원한다면 미리보기 앱에서 PDF를 열고 파일 > 내보내기…를 선택한 뒤 흑백, 회색 톤, 세피아 톤 같은 Quartz 필터를 고르세요.

Apple은 미리보기의 Quartz 필터가 PDF의 색상을 바꾼다고 안내합니다. 예를 들어 컬러 문서를 흑백으로 바꿀 수 있습니다. 파일 크기 줄이기 필터는 이미지를 다시 압축하므로 삽입된 그림에는 약한 JPEG 흐릿함이 더해지지만 텍스트에는 변화가 없습니다.

인쇄 대화상자로는 왜 스캔 느낌이 일부만 날까요?

실제 스캔 페이지는 종이를 찍은 사진입니다. 살짝 회전되어 있고, 윤곽이 부드럽고, 배경이 회색이나 미색이며, 무작위 점이 섞여 있습니다. 인쇄 대화상자는 색을 바꾸고 때로는 래스터화도 하지만, 페이지를 움직이거나 화질을 떨어뜨리지는 않습니다. 결과를 나란히 비교해 보세요.

방법 4: PDF를 손수 스캔한 것처럼 만들기

래스터 이미지 편집기를 쓰면 효과를 하나하나 직접 적용해 PDF를 손수 스캔한 것처럼 만들 수 있습니다. 페이지를 이미지로 내보내고, 살짝 회전하고, 노이즈와 흐림을 더하고, 레벨을 조정한 뒤 다시 PDF로 합치는 방식입니다. 모든 페이지를 완전히 제어할 수 있지만 문서 하나에 10~30분이 걸립니다.

PDF를 스캔한 것처럼 만드는 과정을 단계별로 이해하고 싶다면 모든 효과를 직접 적용하는 이 방법이 가장 많은 것을 알려 줍니다.

회전, 노이즈, 흐림, 레벨 도구가 있는 래스터 편집기라면 무료든 유료든 상관없습니다. 작업 흐름은 어느 편집기에서나 같고 메뉴 이름만 다릅니다. 페이지를 하나씩 따로 작업하거나, 편집기가 지원한다면 과정을 액션이나 매크로로 기록해 두세요.

  1. 페이지를 이미지로 내보냅니다. PDF 뷰어의 내보내기 또는 이미지로 저장 옵션을 사용하세요. 150~300 dpi의 PNG나 고품질 JPEG를 선택합니다. 텍스트라면 200 dpi가 적당한 절충점입니다.
  2. 회색조로 바꿉니다. 문서에 컬러 도장이나 서명이 없다면 먼저 이미지 모드를 회색조로 전환하세요. 그래야 이후 모든 단계가 실제 스캐너에 더 가깝게 작동합니다.
  3. 0.5°~2° 회전합니다. 90° 프리셋이 아니라 임의 각도 회전을 사용하세요. 페이지마다 0.7°, −0.4°, 1.1°처럼 각도를 다르게 하고, 드러난 모서리는 흰색이나 연한 회색으로 채웁니다.
  4. 노이즈를 더합니다. 단색 가우시안 노이즈를 2~5% 적용하세요. 약 8%를 넘으면 스캐너 센서가 아니라 필름 입자처럼 보이기 시작합니다.
  5. 살짝 흐리게 합니다. 200 dpi 기준 반경 0.3~0.6픽셀의 가우시안 흐림을 주면 벡터 텍스트의 칼같이 날카로운 윤곽이 사라집니다.
  6. 레벨을 조정합니다. 검은 점을 조금 올려 검은색이 짙은 회색이 되게 하고, 흰 점을 내려 종이가 옅은 회색이나 미색을 띠게 하세요.
  7. JPEG로 저장합니다. 품질 75~85%로 저장하면 눈에 띄는 블록 없이 실제 스캔 같은 은은한 압축 흐릿함이 더해집니다.
  8. PDF로 다시 합칩니다. 이미지를 순서대로 정리해 PDF 하나로 합치세요. 예를 들어 macOS 미리보기 앱(페이지 선택 > 프린트 > PDF로 저장)이나 윈도우 사진 앱(인쇄 > Microsoft Print to PDF)을 쓸 수 있습니다.

이 수고는 더 어두운 왼쪽 여백, 책 제본선을 따라 생긴 그림자, 손으로 그린 구김처럼 슬라이더에 없는 효과가 필요할 때 보람이 있습니다. 평범한 사무실 스캔 느낌이라면 결과는 방법 1과 사실상 같고 클릭만 훨씬 많아집니다.

방법 5: 휴대폰으로 PDF를 스캔본처럼 만들기

인쇄물을 휴대폰으로 스캔하면 가장 자연스러운 휴대폰 스캔 느낌이 납니다. PDF를 인쇄한 다음 iPhone 메모 앱이나 파일 앱, 또는 여러 안드로이드 카메라 앱과 파일 앱에 내장된 문서 스캐너로 촬영하세요. 휴대폰이 페이지를 자르고 평평하게 펴서 PDF로 저장합니다.

Apple은 iPhone과 iPad에서 메모 앱이나 파일 앱으로 종이 문서를 스캔하고, 스캔을 저장하기 전에 모서리를 끌어 페이지에 맞출 수 있다고 설명합니다. 많은 안드로이드 휴대폰도 기본 카메라 앱이나 파일 앱에 비슷한 문서 모드를 제공하며, 메뉴 이름은 제조사마다 다릅니다.

  1. PDF를 인쇄합니다. 80 g/m² 일반 사무용지와 보통 인쇄 품질이면 충분합니다.
  2. 부드럽고 고른 조명을 씁니다. 창가의 자연광이나 등 뒤의 천장 조명을 이용하면 손과 휴대폰이 만드는 짙은 그림자를 피할 수 있습니다.
  3. 대비되는 바닥에 종이를 놓습니다. 어두운 책상 위에 놓으면 스캐너가 모서리를 자동으로 잘 인식합니다.
  4. 페이지를 하나씩 스캔합니다. 휴대폰을 종이와 평행하게 들고, 자동 자르기를 그대로 쓰거나 모서리를 직접 끌어 맞추세요.
  5. 필터를 고릅니다. 회색조나 "문서" 필터는 사무실 스캔처럼 보이고, 컬러나 사진 필터는 종이 질감과 조명의 차이를 살려 줍니다.
  6. PDF로 저장하거나 공유합니다. 모든 페이지가 여러 페이지짜리 PDF 하나에 담깁니다.

휴대폰 스캔이 아니라 휴대폰 사진이 이미 있다면, 스캔 효과를 더하기 전에 이미지를 자르고 합치는 방법을 다룬 JPG나 휴대폰 사진을 스캔본 PDF로 바꾸는 가이드를 참고하세요.

방법 6: PDF를 실제로 인쇄하고 스캔하기

PDF를 인쇄해 평판 스캐너나 자동 급지 스캐너에 통과시키면 흉내가 아닌 진짜 스캔 문서가 만들어집니다. 텍스트는 200~300 dpi 회색조로 스캔해 PDF로 저장하세요. 실제 기울어짐, 먼지, 토너 질감, 약간의 대비 손실이 그대로 남습니다.

참고로 미국 연방 규정은 본격적인 디지털화에 최저 기준을 둡니다. 미국 국립문서기록관리청(NARA) 규정은 현대 문서 기록물에 대해 이렇게 명시합니다. "이러한 기록물은 원본 문서 크기 기준 최소 300 ppi로 이미지 파일을 생성해야 한다." 같은 규정은 약 294 ppi, 즉 300 ppi에서 2%를 뺀 값까지 허용합니다.

FADGI(미국 연방기관 디지털화 가이드라인)는 제본되지 않은 문서를 별 1개인 약 200 ppi부터 별 4개인 400 ppi까지 별점 등급으로 평가합니다. 일상적인 사무실 스캔은 보통 이 범위의 아래쪽에 있으므로, 편지나 양식은 200 dpi만으로도 진짜처럼 보입니다.

해상도
일반적인 사무실 느낌은 200 dpi, 법원이나 기관이 지정한 경우 300 dpi.
색상 모드
대부분의 텍스트는 회색조, 강한 팩스나 복사기 느낌은 흑백(1비트), 원본에 색이 있을 때만 컬러.
용지
일반 사무용지. 살짝 미색을 띠는 종이나 재생지를 쓰면 자연스러운 색감이 더해집니다.
배치
종이를 원고대 가이드에 완벽하게 맞추지 마세요. 자연스럽게 아주 살짝 기울어지는 것이 핵심입니다.

기울어짐은 저절로 생깁니다. FADGI는 "캡처된 이미지에 나타나는 기울어짐은 대개 카메라의 초점면과 원고대가 평행하지 않은 데서 비롯된다"고 설명합니다. 방법 1의 회전 편차 슬라이더가 흉내 내는 것이 바로 이렇게 페이지마다 달라지는 작은 기울어짐입니다.

PDF를 스캔 문서처럼 보이게 하는 설정은?

PDF를 스캔 문서처럼 보이게 하는 설정은 어떤 스캔을 흉내 내고 싶은지에 따라 달라집니다. 깔끔한 사무실 스캔, 복사본, 팩스 같은 페이지, 누렇게 바랜 종이, 휴대폰 스캔 느낌의 5가지 설정 조합이면 대부분의 경우를 해결할 수 있습니다. 아래 값은 모두 브라우저 도구에 그대로 입력하면 됩니다.

특정한 종류의 스캔 문서처럼 PDF를 만들고 싶다면 해당하는 행을 고르세요.

이 설정 조합은 일반적인 편지, 청구서, 양식으로 맞춘 저희만의 출발점입니다. 기준값으로 생각하세요. 설정 조합을 불러오고, 미리보기를 100%로 확대한 뒤, 문서에 맞아 보일 때까지 슬라이더를 하나씩 바꿔 보면 됩니다.

사무실 스캔: 무난한 기본값

양식에 그냥 "스캔본을 업로드하세요"라고 적혀 있다면 사무실 스캔 설정 조합을 쓰세요. 낮은 노이즈와 0.5° 기울기는 관리가 잘된 사무실 스캐너처럼 보이고, 대비를 살짝 올리면 작은 글씨도 잘 읽힙니다. 2×에서 페이지 이미지는 약 144 dpi로, 화면에서 편하게 읽기에 충분합니다.

복사본 느낌과 팩스 느낌

복사본은 더 거칠어 보입니다. 대비가 높아 회색 톤이 흑과 백으로 뭉개지고, 테두리 선은 복사기가 흔히 남기는 어두운 가장자리를 흉내 냅니다. 팩스 느낌 설정 조합은 여기서 더 나아가 노이즈를 늘리고 1.5×(약 108 dpi)를 사용합니다. 이는 표준 모드 G3 팩스의 세로 해상도인 인치당 약 100라인에 가깝습니다.

누렇게 바랜 종이와 휴대폰 스캔 느낌

누렇게 바랜 종이를 원한다면 컬러로 바꾸고 누런 톤을 약 0.6까지 올리면서 밝기는 조금 낮추세요. 페이지가 따뜻한 미색을 띠게 됩니다. 휴대폰 스캔 설정 조합은 2°로 더 크게 기울이고 따뜻한 색을 살짝 더해, 실내 조명 아래에서 찍은 페이지처럼 보이게 합니다. 더 많은 프리셋은 스캔 효과 설정 가이드에서 확인하세요.

작은 글씨는 읽을 수 있게 유지하세요문서에 각주나 9 pt 미만의 글씨가 있다면 흐림을 0.3 이하로 두고 해상도 2.5× 또는 3×를 사용하세요. 흐림과 노이즈는 작은 글씨부터 망가뜨리며, 읽을 수 없는 스캔본은 쓸모가 없습니다.

PDF가 스캔한 것처럼 보이는지 확인하는 방법은?

PDF가 스캔한 것처럼 보이는지 확인하려면 100% 배율로 열고 다섯 가지를 살펴보세요. 텍스트를 선택할 수 없는지, 페이지마다 각도가 조금씩 다른지, 윤곽이 칼같이 날카롭지 않고 부드러운지, 배경이 순백색이 아닌지, 파일 속성에 더 이상 워드 프로세서 이름이 나오지 않는지입니다.

실제 스캔본에는 기록 관리 전문가들이 없애려고 애쓰는 결함이 있습니다. NARA 규정은 그중 하나를 이렇게 정의합니다. "노이즈란 디지털화된 기록물에 나타나는, 원본 자료에 속하지 않는 하나 이상의 원치 않는 이미지 아티팩트이다." 그럴듯한 스캔 느낌에는 이런 노이즈가 전혀 없어도, 너무 많아도 안 되고 적당히 조절된 소량이 필요합니다.

  1. 텍스트를 선택해 봅니다. PDF 뷰어에서 Ctrl+A 또는 Cmd+A를 누르세요. 스캔본 같은 PDF에서는 각 페이지가 이미지이므로 아무것도 선택되지 않습니다.
  2. 단어를 검색해 봅니다. 일부러 OCR을 추가하지 않았다면 Ctrl+F 또는 Cmd+F로 아무것도 찾을 수 없어야 합니다.
  3. 페이지 각도를 비교합니다. 여러 페이지를 넘겨 보세요. 회전 편차를 켰다면 페이지마다 기울기가 조금씩 달라야 합니다.
  4. 200%로 확대합니다. 글자 윤곽이 선명한 벡터 외곽선이 아니라 살짝 부드럽고 옅은 점이 섞여 보여야 합니다.
  5. 여백을 봅니다. 종이가 순백색이 아니라 아주 연한 회색이나 미색이어야 합니다.
  6. 문서 속성을 엽니다. 제작 프로그램과 작성 프로그램 항목을 확인하세요. 이 도구에서는 제목, 작성자, 주제, 키워드, 제작 프로그램, 작성 프로그램을 편집할 수 있습니다.
  7. 파일 용량을 확인합니다. 스캔본 같은 PDF는 텍스트 대신 이미지를 저장하므로 원본보다 크며, 몇 배가 되는 경우도 많습니다.
  8. 한 페이지를 인쇄해 봅니다. 팔을 뻗은 거리에서 인쇄물을 읽을 수 있다면 어떤 업로드 포털에 올려도 괜찮은 설정입니다.

업로드할 때는 파일 용량이 중요합니다. 대략적으로 텍스트 페이지는 회색조 2×에서 보통 수백 킬로바이트 초반이고, 컬러 3×에서는 그 몇 배가 될 수 있습니다. 포털에 용량 제한이 있다면 해상도를 1.5×로 낮추거나 회색조로 바꾸세요. DPI와 용량 사이의 균형은 PDF 스캔본 변환 가이드에서 자세히 다룹니다.

가짜 스캔 PDF가 티 나는 이유는?

가짜 스캔 PDF가 티 나는 이유는 대개 효과 하나가 지나치거나 디지털 파일의 흔적 하나가 남아 있기 때문입니다. 모든 페이지가 똑같이 기울어져 있거나, 흐림이 심하거나, 노이즈가 거칠거나, 배경이 순백색이거나, 텍스트를 선택할 수 있는 경우입니다. 이 다섯 가지 실수만 고쳐도 저희가 접하는 문제는 대부분 해결됩니다.

이 도구로 구김, 얼룩, 그림자도 넣을 수 있나요?

PDF를 스캔한 것처럼 만들면 안 되는 경우는?

받는 사람에게 검색 가능한 텍스트가 필요할 때, 규정상 텍스트 기반 PDF를 요구할 때, 스캔 느낌 때문에 문서의 출처가 잘못 전달될 수 있을 때는 PDF를 스캔한 것처럼 만들면 안 됩니다. 법원, 접근성 표준, 많은 기관은 텍스트를 찍은 이미지보다 디지털 PDF를 선호합니다.

미국 연방법원은 이 점을 분명히 밝힙니다. 캘리포니아 북부 연방지방법원은 "PDF로 직접 변환할 수 없는 문서만 스캔해야 한다"고 안내합니다. 매사추세츠 연방지방법원은 "스캔한 PDF 문서는 일반적으로 검색할 수 없고 파일 용량이 더 크다"고 덧붙입니다.

또 다른 이유는 접근성입니다. W3C의 WCAG(웹 콘텐츠 접근성 지침) 기법 PDF7은 "텍스트를 스캔한 이미지로 이루어진 문서는 콘텐츠가 검색 가능한 텍스트가 아니라 이미지이므로 본질적으로 접근성이 없다"고 명시합니다. 나중에 OCR을 추가하지 않는 한 스크린 리더 사용자는 스캔 효과를 적용한 PDF를 읽을 수 없습니다.

스캔 효과는 정직하게 사용하세요스캔 효과는 파일의 겉모습을 바꿀 뿐, 문서가 진짜인지 여부를 바꾸지는 않습니다. 공문서, 신분증, 증명서, 본인 것이 아닌 서명을 위조하거나 변조하는 데 사용하지 마세요. 법원, 고용주, 기관이 특정 형식을 요구한다면 그 규칙을 따르세요. 일부 기관은 텍스트 검색이 가능한 PDF를 요구하며 텍스트를 찍은 이미지는 받지 않습니다.

PDF를 스캔한 것처럼 만들 만한 정당한 이유로는 종이 기반 보관 문서와 스타일을 맞추는 경우, 디자인 목업이나 교육용 예시를 준비하는 경우, 문서 처리 소프트웨어를 실제와 비슷한 입력으로 테스트하는 경우, 본인이 가진 것은 디지털 원본뿐인데 양식이 "스캔본"을 고집하는 경우 등이 있습니다.

사람들이 PDF를 인쇄했다가 곧바로 다시 스캔하는 일을 계속 반복하는 것을 보고 이 도구를 만들었습니다. 진짜처럼 보이는 설정은 작은 값입니다. 1도 이하의 기울기, 0.1 안팎의 노이즈, 약한 흐림이면 충분합니다. 가짜처럼 보이는 결과는 대부분 모든 슬라이더를 한꺼번에 올린 탓입니다. 그리고 파일을 로컬에서 처리하는 것은 의도한 설계입니다. 사람들이 스캔하는 문서는 대개 개인적인 문서이기 때문입니다.

PDF 스캔한 것처럼 만들기: 자주 묻는 질문

PDF를 스캔한 것처럼 만들고 싶을 때 사람들이 가장 자주 묻는 질문을 개인정보 보호와 비용부터 워드 파일, 서명, 파일 용량까지 모았습니다. 각 답변은 짧고 따로 읽어도 이해되도록 썼으며, 방법과 설정은 위 섹션에서 더 자세히 설명합니다.

어떤 방법을 골라야 하는지, 결과물의 보안은 괜찮은지, 작은 글씨를 어떻게 읽을 수 있게 유지하는지, 그리고 휴대폰에서, 양식 제출용으로, 보관용으로 PDF를 스캔본처럼 만드는 방법까지, PDF를 스캔한 것처럼 만들 때 가장 많이 나오는 질문에 답합니다.

PDF를 무료로 스캔한 것처럼 만들려면 어떻게 하나요?

무료 스캔 도구를 열고 PDF를 끌어다 놓은 뒤, 기본 설정을 그대로 두거나 설정 조합을 골라 결과를 다운로드하세요. 비용이 들지 않고 계정도 필요 없으며, 휴대폰을 포함해 최신 브라우저라면 어디서나 작동합니다.

개인적인 PDF를 스캔 효과 도구에 올려도 안전한가요?

Make PDF look scanned 도구에서는 업로드 자체를 하지 않습니다. 페이지는 PDF.js와 캔버스를 이용해 브라우저에서 로컬로 렌더링되고 처리됩니다. 파일은 처리용 서버로 전송되지 않으며, 처음 한 번 로드한 뒤에는 오프라인에서도 도구가 작동합니다.

스캐너 없이 PDF를 스캔 문서처럼 만들려면 어떻게 하나요?

방법 1이나 방법 2를 사용하세요. 둘 다 각 페이지를 회전하고, 흐리게 하고, 노이즈를 더해 소프트웨어로 스캐너를 흉내 냅니다. 스캐너 없이 진짜 스캔 흔적을 원한다면 페이지를 인쇄해 휴대폰에 내장된 문서 스캐너를 사용하세요(방법 5).

워드 문서를 스캔한 것처럼 만들려면 어떻게 하나요?

먼저 워드 파일을 PDF로 저장하고(파일 > 다른 이름으로 저장 > PDF) 그 PDF에 스캔 효과를 적용하세요. DOCX를 바로 업로드하면 원본 텍스트만 A4 페이지에 Helvetica 11 pt로 남으므로 글꼴, 표, 이미지가 사라집니다.

스캔본 같은 PDF의 DPI는 얼마가 적당한가요?

약 150~200 dpi면 일반적인 사무실 스캔처럼 보입니다. 이 도구에서 2×는 약 144 dpi, 3×는 약 216 dpi입니다. 법원과 기록 보관 기관은 실제 스캔에 300 dpi를 요구하는 경우가 많은데, 이 값은 실제 스캐너로만 맞출 수 있습니다.

여러 PDF를 한 번에 스캔한 것처럼 만들 수 있나요?

네. 일괄 스캔 페이지와 Chrome 확장 프로그램은 여러 파일을 받아 모든 파일에 같은 설정을 적용하고 결과를 ZIP 파일 하나로 다운로드합니다. 입력한 파일마다 스캔 PDF가 따로 만들어집니다.

스캔 효과를 적용한 뒤에도 텍스트를 검색할 수 있나요?

아니요. 각 페이지가 새 PDF 안에 JPEG 이미지로 저장되므로 텍스트를 선택하거나 검색할 수 없습니다. 검색 가능한 텍스트가 필요하다면 별도 소프트웨어로 결과물에 OCR을 실행하거나 원본 PDF를 보관해 두세요.

스캔본 같은 PDF에 서명이나 도장을 넣을 수 있나요?

네. 이 도구는 스캔 효과를 적용하기 전에 위치와 크기를 조절할 수 있는 도장 또는 서명 이미지를 넣을 수 있어, 서명이 페이지에 자연스럽게 섞입니다. 본인의 서명이나 사용 권한이 있는 서명만 넣으세요.

스캔본 같은 PDF가 왜 가짜처럼 보일까요?

대개 기울기가 너무 크거나, 모든 페이지가 똑같이 기울어져 있거나, 흐림과 노이즈가 너무 강하기 때문입니다. 회전은 0.5°~2°로 두고, 회전 편차를 켜고, 흐림은 0.3 안팎, 노이즈는 0.1~0.25 정도로 유지하세요.

iPhone이나 안드로이드에서 PDF를 스캔한 것처럼 만들 수 있나요?

네. 웹사이트가 모바일 브라우저에서 작동하므로 휴대폰에서 도구를 열고 파일 앱에서 PDF를 골라 결과를 다운로드할 수 있습니다. 아니면 문서를 인쇄해 휴대폰에 내장된 문서 스캐너로 촬영해도 됩니다.

스캔 효과를 적용하면 파일이 커지나요?

대개 그렇습니다. 페이지가 텍스트가 아니라 이미지로 저장되기 때문입니다. 회색조 1.5×나 2×가 파일을 가장 작게 유지하고, 컬러 3×가 가장 큽니다. 업로드 포털에 용량 제한이 있다면 해상도를 낮추세요.

PDF를 스캔한 것처럼 만드는 것은 합법인가요?

본인 문서의 겉모습을 바꾸는 것은 일반적으로 문제가 없습니다. 중요한 것은 용도입니다. 변조하거나 위조한 문서를 진짜처럼 내세우면 불법이 될 수 있습니다. 법원이나 기관이 파일 규정을 정해 두었다면 그 규정을 따르세요. 많은 곳이 텍스트 검색이 가능한 PDF를 선호합니다.

PDF를 스캔한 것처럼 만드는 방법, 무엇을 고를까요?

대부분의 사람에게 PDF를 스캔한 것처럼 만드는 가장 좋은 방법은 무료 브라우저 도구입니다. 1분이 채 걸리지 않고, 로컬에서 처리되며, 기울기, 흐림, 노이즈를 정확하게 조절할 수 있습니다. 여러 파일을 자주 처리한다면 Chrome 확장 프로그램을, 진짜 스캔본이 꼭 필요할 때만 실제 스캐너를 고르세요.

인쇄 대화상자는 빠르게 회색조 버전만 필요할 때, 이미지 편집기는 제본선 그림자 같은 맞춤 효과를 원할 때, 휴대폰 경로는 속도보다 진짜 휴대폰 스캔 느낌이 더 중요할 때 선택하세요. 사람들이 차이를 어떻게 알아보는지 궁금하다면 스캔 PDF란 무엇이고 어떻게 구별하는지 읽어 본 뒤, 스캐너를 열고 내 파일에 사무실 스캔 설정 조합을 적용해 보세요.
