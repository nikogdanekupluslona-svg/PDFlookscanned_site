# Glossario italiano (it) — pdflookscanned.com

Mercato: Italia e Svizzera italiana. Lingua: italiano standard d'Italia. This file is binding for every Italian
page (UI, home guide, blog chrome, 7 articles). If a term is here, use it exactly; if a UI label is quoted in
the text, copy it from the "Interface labels" table (it mirrors `lookscanned.io-main/src/locale/messages/it.json`).

## Address form and style

- **Address the reader with "tu"** (informal, as on modern Italian tool sites): "trascina il file", "puoi",
  "il tuo PDF". Never "Lei"/"voi". Imperatives in the 2nd person singular: Apri, Trascina, Scegli, Regola,
  Scarica, Fai clic su…
- Headings: sentence case (only the first word and proper names capitalized): "Come far sembrare un PDF
  scansionato online". Question headings stay questions ("Quale risoluzione conviene usare?").
- Short, plain sentences; answer first. Avoid calques: "fare senso" (→ "avere senso"), "realizzare" for "to
  realize" (→ "rendersi conto"), "eventualmente" for "eventually" (→ "alla fine"), "supportare" for "to help"
  (fine for file formats: "formati supportati"), "applicare per" (→ "fare domanda per").
- The brand **Make PDF look scanned** stays in English (masculine when needed: "lo strumento gratuito
  Make PDF look scanned", "il team Make PDF look scanned"). Never translate it, never write "lookscanned".
- Loanwords used as in Italian tech writing, invariable in the plural: il/i PDF, il/i file, il browser, lo
  scanner, lo ZIP (article "uno ZIP"), il cloud, il download, l'upload (only in snippets), il preset, il mockup,
  offline/online, lo smartphone, la privacy, l'app. Do not add an -s plural ("i file", not "i files").
- "Chrome Web Store", "Google Chrome", "Microsoft Edge", "Windows", "macOS", "iPhone", "Android" keep their names.
  "estensione" is feminine: "l'estensione Chrome", "installata", "gratuita".
- Quotation marks: caporali « » in running text ("una «copia scansionata»"); straight apostrophe ' (un'immagine,
  cos'è). Menu paths with → and the exact Italian menu names in plain text: File → Esporta….
- No emoji, no exclamation marks in running text.
- Gender/number agreement with keywords: "far sembrare scansionato un documento" / "far sembrare scansionati i
  file"; the main keywords are fixed phrases, keep them in the exact form where they are placed for SEO.

## Numbers, units, dates

- Decimal separator: comma — 0,3 · 0,5° · 1,1 · 0,05–0,2. Values themselves never change.
- Thousands separator: dot — 2.200 px, 10.000 pagine. (Swiss usage 2'200 is NOT used; the site targets Italy
  first and dot is understood in Ticino.)
- Ranges with an en dash and no spaces: 0,5–2°, 20–60 secondi, 300–400%. "da −10° a 10°" when a range starts
  with a negative number.
- Degree sign attached: 1°, 0,5°. Multiplier: 2×, 3× (× sign, no space). Percent attached as in the source: 400%.
- Units: dpi, ppi, px, pt, MB, KB (as in source), "pollici" for inches (0,75 pollici), mm for paper sizes.
- Paper: A4 is the default in Italy; "formato Letter (USA)" when the source mentions Letter.
- Dates: "18 settembre 2026", "settembre 2026" (months lowercase). Numeric: 18/09/2026.
- Times: "meno di un minuto", "10–20 minuti", "in pochi secondi".
