이미지를 스캔본 PDF로 바꾸려면 무료 스캔 도구를 열고 JPG, PNG나 휴대폰 사진을 넣은 뒤 살짝 기울기를 주고 약한 노이즈와 회색조를 설정한 다음 결과물을 다운로드하세요. 이미지 스캔본 PDF 변환은 브라우저에서 이루어지며, 사진을 A4 페이지에 배치하고 스캔본 느낌의 PDF로 저장합니다.

서명한 양식을 찍은 사진은 사무실 스캔본처럼 보이는 경우가 드뭅니다. 색감이 어긋나고, 가장자리가 비뚤어지고, 파일이 PDF가 아니라 JPG이기 때문입니다. 이 가이드는 카메라로 찍은 사진부터 스캔 PDF까지 전체 과정, 즉 사진 준비, 픽셀 계산, 형식, 여러 이미지 합치기를 다룹니다. 근거는 미국 시민이민서비스국(USCIS), 미국 국립문서기록관리청(NARA), FADGI, Apple 지원 문서와 저희 도구의 소스 코드입니다.

이미지를 스캔본 PDF로 바꾸는 가장 빠른 방법은?

이미지를 스캔본 PDF로 바꾸는 가장 빠른 방법은 사진을 바로 받아들이는 브라우저 도구를 쓰는 것입니다. Make PDF look scanned는 JPG나 PNG를 받아 PDF 페이지에 담고, 스캐너 특유의 기울기, 흐림, 노이즈, 회색 톤을 더해 약 1분 만에 새 PDF를 내보냅니다. 업로드도 회원가입도 필요 없습니다.

입력
JPG, PNG, WebP, SVG, GIF 또는 BMP(이미지 파일 1개 = 페이지 1장)
출력
스캔 효과가 적용된 JPEG 이미지 페이지로 된 PDF
페이지 크기
이미지 방향에 맞춘 A4 세로 또는 가로

비용
무료, 계정 불필요, 직접 추가하지 않는 한 워터마크 없음

사진이 이미 PDF라면(예: 스캔 앱이 내보낸 PDF) 변환 이야기는 건너뛰고 PDF를 스캔본 PDF로 바꾸는 가이드를 읽어 보세요. 이 형식 자체에 대한 더 넓은 배경지식이 필요하다면 스캔 PDF란 무엇인지 확인하세요.

이미지를 스캔본 PDF로 변환하는 방법은?

이미지를 스캔본 PDF로 변환하려면 반듯하게 자른 사진을 준비하고, Chrome이나 Edge, 또는 모바일 브라우저에서 스캐너 페이지를 열어 파일을 불러온 뒤 실시간 미리보기를 보면서 스캔 효과를 조정하고 PDF를 다운로드하세요. 아래 전체 과정은 이미지 1장당 1~2분이 걸립니다.

  1. 이미지를 준비합니다. 사진을 종이 가장자리에 맞춰 자르고 휴대폰 내장 편집기나 문서 스캐너로 반듯하게 펴세요. 도구는 자르기, 기울기 보정, 원근 보정을 하지 않으므로, 불러온 모습 그대로 스캔됩니다.
  2. HEIC 사진을 JPG로 내보냅니다. 아이폰 사진은 대개 HEIC 파일입니다. 도구가 HEIC는 받지 않고 JPG, PNG, WebP, SVG, GIF, BMP만 받으므로 먼저 JPG로 내보내거나 공유하세요.
  3. 스캐너를 엽니다. pdflookscanned.com/scan에 접속하거나 Chrome 확장 프로그램의 측면 패널을 여세요. 둘 다 같은 엔진을 사용하며 처음 불러온 뒤에는 오프라인에서도 작동합니다.
  4. 이미지를 넣습니다. JPG나 PNG를 업로드 영역에 끌어다 놓으세요. 도구는 세로로 긴 이미지는 세로 A4에, 가로로 넓은 이미지는 가로 A4에 맞춰 축소하고 가운데 배치합니다.
  5. 스캔 느낌을 설정합니다. 색 공간 회색조, 회전 1°, 회전 편차 0.5°, 흐림 0.3, 노이즈 0.1로 시작하세요. 오래된 종이 느낌을 원하면 누런 톤을 0.2나 0.3으로 올리세요.
  6. 해상도를 정합니다. 일반 문서는 2×를 유지하고, 작은 글자나 도장, 서명처럼 읽기 쉬워야 하는 부분이 있으면 2.5×나 3×를 선택하세요.
  7. 필요하면 추가 요소를 더합니다. 원한다면 도장이나 서명 이미지, 워터마크를 넣거나 메타데이터 패널에서 PDF 제목과 작성자를 수정하세요.
  8. 다운로드하고 확인합니다. 스캔 PDF를 저장하고 평소 쓰는 PDF 뷰어에서 열어 100%로 확대해 모든 줄이 읽히는지 확인하세요.
이미지 1장, 페이지 1장각 이미지 파일은 별도의 한 페이지짜리 PDF가 됩니다. 여러 사진으로 여러 페이지짜리 스캔 PDF를 만들려면 먼저 운영체제 기능으로 이미지를 PDF 한 개로 합친 뒤, 그 PDF를 도구에 넣으세요. 여러 이미지 섹션에서 정확한 클릭 순서를 보여 드립니다.

문서를 찍을 때 휴대폰 사진은 어떻게 찍어야 하나요?

문서를 찍은 좋은 휴대폰 사진은 바로 위에서, 평평하고 어두운 바닥 위에서, 그림자 없이 고른 낮 빛 아래에서 촬영하고 종이 가장자리에 맞춰 자른 사진입니다. 이런 준비가 어떤 필터보다 중요합니다. 스캔 효과는 접힌 모서리나 손 그림자처럼 사진에 이미 있는 결함을 그대로 복사하기 때문입니다.

온라인 제출에서 휴대폰 사진을 증빙으로 인정하는 미국 시민이민서비스국(USCIS)은 최소 기준을 간단히 이렇게 밝힙니다. "첨부하는 각 이미지가 선명하고 모든 텍스트가 읽을 수 있는지 확인하세요." 같은 페이지는 신청자에게 "스캐너를 사용하거나 각 문서를 사진으로 찍으세요."라고도 안내합니다. 즉 신중하게 찍은 사진은 우회 수단이 아니라 인정되는 출발점입니다.

사진을 스캔본 PDF로 만들 때 조명, 바닥, 각도

  • 조명: 창가의 간접 낮 빛이나 양쪽에서 비추는 조명 두 개를 사용하세요. 머리 위 조명 하나만 쓰면 휴대폰 그림자가 페이지에 드리워집니다.
  • 바닥: 흰 종이를 더 어두운 탁자 위에 두면 가장자리를 감지하고 자르기 쉽습니다. 접힌 자국은 먼저 책 밑에 1분 정도 눌러 펴세요.
  • 각도: 휴대폰을 페이지와 평행하게, 중심 바로 위에 두세요. 휴대폰이 기울면 먼 쪽 가장자리가 가까운 쪽보다 좁게 나옵니다.
  • 거리: 얇은 여백만 남기고 프레임을 페이지로 채우세요. 디지털 줌 대신 기본 카메라를 사용하세요.
  • 플래시: 플래시는 끄세요. 광택 있는 종이에 밝은 반점과 눈부심을 만듭니다.

이 각도 규칙에는 기술적 근거가 있습니다. 미국 연방 디지털화 실무 그룹인 FADGI는 "촬영된 이미지의 기울어짐 현상은 카메라의 초점면과 원고대가 평행하지 않은 데서 비롯되는 경우가 많다"고 설명합니다. 쉽게 말하면 휴대폰이 종이와 평행하지 않으면 페이지가 사다리꼴로 나오는데, 이는 어떤 평판 스캐너에서도 나오지 않는 모양입니다.

아이폰이나 안드로이드의 내장 문서 스캐너 사용하기

휴대폰에는 이미 자르기와 반듯하게 펴기를 대신해 주는 무료 문서 모드가 있습니다. 아이폰이나 아이패드에서는 메모 앱과 파일 앱이 카메라로 문서를 스캔하고, 자동 모드에서 페이지를 감지해 모서리를 조정할 수 있게 해 줍니다. Apple의 안내는 이렇게 말합니다. "그런 다음 모서리를 끌어 스캔을 페이지에 맞게 조정한 뒤 스캔 유지를 탭하세요."

많은 안드로이드 휴대폰도 기본 카메라나 내장 파일 관리자 안에 비슷한 문서 모드를 제공하며, 페이지 가장자리를 감지해 원근을 평평하게 만들어 줍니다. 메뉴 이름은 제조사마다 다르므로 "문서" 또는 "스캔" 옵션을 찾아보세요. 결과를 이미지나 PDF로 저장한 뒤 스캔 효과 도구에 넣어 휴대폰으로 찍은 사진이 아니라 평판 스캔처럼 보이게 만드세요.

스캔 효과 전에 사진을 자르고 밝게 만들기

일반 사진을 찍었다면 휴대폰 사진 편집기에서 열어 자르기로 탁자 부분을 없애고, 반듯하게 펴기 슬라이더로 텍스트 줄을 수평으로 맞추세요. 그런 다음 노출이나 밝기를 조금 올려 종이가 회색빛 파란색이 아니라 흰색에 가깝게 만드세요. 도구 자체의 밝기와 대비 슬라이더로 마무리할 수 있습니다. 밝기 1.1과 대비 1.2는 가는 획을 잃지 않으면서 흐릿한 사진을 대개 하얗게 만들어 줍니다.

밝게 만드는 것이 중요한 이유평판 스캐너는 몇 밀리미터 거리에서 페이지를 고르게 비추므로 종이가 거의 흰색으로 나옵니다. 실내 조명 아래 휴대폰 사진은 종이가 색이 도는 옅은 회색으로 나옵니다. 배경을 밝게 만드는 것이 사진을 스캔본처럼 보이게 하는 단 하나의 변화입니다.

스캔 PDF 페이지에는 몇 픽셀이 필요한가요?

스캔 PDF 페이지에 필요한 픽셀 수는 용지 크기에 해상도를 곱한 값과 맞아야 합니다. 300ppi의 레터(Letter) 페이지는 2,550×3,300px이고, 300ppi의 A4 페이지는 약 2,480×3,508px입니다. 대부분의 휴대폰 카메라는 이보다 더 많은 픽셀을 찍으므로 해상도가 약점이 되는 경우는 드뭅니다.

계산은 곱셈 한 번이면 됩니다. 인치 × 인치당 픽셀 수 = 픽셀 수입니다. 레터 용지는 8.5×11인치이고, A4는 210×297mm, 약 8.27×11.69인치입니다. 일반적인 1,200만 화소 휴대폰 사진은 4,032×3,024px이므로, 프레임 대부분을 페이지가 채울 경우 주변에 남은 탁자 면적에 따라 대략 250~350ppi 정도가 나옵니다.

연방 디지털화 규정도 같은 기준을 사용합니다. 36 CFR Part 1236, Subpart E에 따르면 NARA의 규정은 현대 텍스트 기록의 이미지 파일에 최소 300ppi를, 정밀한 사진 인화물과 종이 기록에는 400ppi를 요구합니다. FADGI의 별점 체계는 제본되지 않은 문서를 1성부터 4성까지 각각 200, 250, 300, 400ppi로 평가합니다.

픽셀 수만으로는 품질이 보장되지 않으며, NARA도 이를 직접 밝히고 있습니다. "기관은 디지털 이미지 품질을 보장하기 위해 스캐너 ppi 설정이나 카메라 센서 화소 수 같은 장비 사양만 믿을 수 없다." 선명한 2,000픽셀 사진이 흐릿한 4,000픽셀 사진보다 더 잘 읽히므로, 초점과 조명이 여전히 가장 우선입니다.

이미지 스캔본 PDF의 출력 해상도는 어느 정도인가요?

도구는 72dpi에 해상도 설정값을 곱한 값으로 각 페이지를 렌더링합니다. 모든 이미지가 A4 페이지에 배치되므로 출력값은 예측 가능합니다. 1×는 약 595×842px, 2×는 약 1,191×1,684px(144dpi), 3×는 약 1,786×2,526px(216dpi)입니다. 원본 사진이 3× 크기보다 커도 결과물에 추가되는 디테일은 없습니다.

JPG를 스캔본 PDF로 바꿀 때 어떤 이미지 형식을 쓸 수 있나요?

JPG를 스캔본 PDF로, PNG를 스캔본 PDF로 바꾸는 것은 바로 가능합니다. 도구가 이 두 형식을 있는 그대로 PDF 페이지에 삽입하기 때문입니다. WebP, SVG, GIF, BMP도 사용할 수 있지만 먼저 긴 변이 2,200px로 제한된 JPEG로 변환됩니다. HEIC는 지원하지 않습니다.

변환된 WebP, SVG, GIF, BMP의 투명한 영역은 종이와 어울리도록 흰색으로 채워집니다. 2,200px 제한은 A4 페이지의 3× 출력 렌더링보다 여전히 크므로, 변환 과정에서 최종 선명도가 떨어지지 않습니다.

아이폰 HEIC 사진을 JPG로 바꾸는 방법

Mac에서는 미리보기 앱으로 HEIC 파일을 열고 파일 > 내보내기를 선택해 JPEG를 고르세요. Apple의 미리보기 가이드는 내보내기 형식으로 JPEG, PNG, PDF, TIFF를 소개합니다. 아이폰에서는 설정 > 카메라 > 포맷을 높은 호환성으로 설정하면 바로 JPG로 촬영됩니다.

사진과 스크린샷에는 어떤 스캔 설정이 맞나요?

휴대폰 사진에는 가벼운 스캔 설정이 맞습니다. 사진에는 이미 자연스러운 부드러움과 입자감이 있기 때문입니다. 스크린샷과 내보낸 이미지는 픽셀 하나하나가 선명해 디지털처럼 보이므로 효과를 조금 더 줘야 합니다. 두 경우 모두 회색조, 1.5° 미만의 기울기, 0.2 이하의 노이즈면 평범한 사무실 스캐너처럼 보입니다.

사람들이 도구에 넣는 거의 모든 이미지에서 같은 패턴을 봅니다. 문제는 스캔 효과가 아니라 사진 자체입니다. 비뚤어지고 그림자 지고 노이즈를 최대로 준 사진은 여전히 휴대폰 사진처럼 보입니다. 반듯하게 자르고 밝게 만든 페이지에 회전 0.5°, 흐림 0.2, 회색조를 적용하면 평판 스캐너에서 나온 것처럼 보입니다. 사진부터 고치고 효과는 은은하게 유지하세요.

여러 이미지를 하나의 스캔 PDF로 합치려면?

여러 이미지를 하나의 스캔 PDF로 합치려면 먼저 macOS나 Windows에 내장된 기능으로 이미지들을 일반 PDF 하나로 합친 뒤, 그 PDF를 스캐너에 넣으세요. 도구는 페이지 순서를 유지하며 모든 페이지에 스캔 효과를 적용하고, 페이지마다 약간의 무작위 기울기를 더합니다.

Mac 미리보기 앱으로 이미지를 PDF 하나로 합치기

  1. 이미지 이름을 페이지 순서대로 지정한 뒤(01.jpg, 02.jpg…) Finder에서 모두 선택하고 미리보기 앱으로 엽니다.
  2. 썸네일 사이드바에서 페이지 순서를 끌어다 맞춘 뒤 Command-A를 누릅니다.
  3. 파일 > 프린트를 선택하고 왼쪽 아래의 PDF 메뉴를 열어 PDF로 저장을 고릅니다.

Windows에서 이미지를 PDF 하나로 합치기

  1. 파일 탐색기에서 이미지를 선택하고 마우스 오른쪽 버튼을 눌러 인쇄를 선택합니다(Windows 11에서는 더 많은 옵션 표시 안에 있습니다).
  2. Microsoft Print to PDF와 전체 페이지 사진 레이아웃을 고른 뒤, 가장자리가 잘리지 않도록 "프레임에 맞게 사진 조정"을 해제합니다.
  3. 인쇄를 클릭하고 PDF를 저장합니다.

다음으로 스캐너를 열고 합친 PDF를 넣은 뒤, 페이지마다 기울기가 조금씩 다르도록 회전 편차를 0.5°~1°로 설정하고 다운로드하세요. 인쇄된 PDF는 보통 레터나 A4 페이지를 사용하므로 스캔본도 같은 크기를 따릅니다.

여러 이미지, 개별 파일합친 파일 하나 대신 이미지마다 스캔 PDF가 하나씩 필요하다면 일괄 스캔을 사용하세요. 모든 이미지를 넣고 설정을 한 번만 지정한 뒤, 이미지 1장당 PDF 1개씩 담아 ZIP 파일 하나로 모두 다운로드할 수 있습니다.

사진을 스캔본 PDF로 바꾸면 파일 용량은 얼마나 되나요?

사진을 스캔본 PDF로 바꾼 파일은 대개 원본 사진보다 훨씬 작습니다. 도구가 각 A4 페이지를 정해진 크기의 JPEG로 렌더링하기 때문입니다. 기본값인 2× 회색조 설정에서는 보통 페이지당 수백 킬로바이트가 나오며, 이는 USCIS의 12MB 제한 같은 업로드 용량 한도에 맞습니다.

출력 용량은 카메라가 아니라 렌더링 결과에 좌우됩니다. 5MB짜리 휴대폰 사진은 A4 페이지에 맞춰 축소되어 2×에서 1,191×1,684px로 다시 렌더링되므로, 남는 픽셀 대부분은 버려집니다. 저희 추정으로는 회색조 2×에서 페이지당 약 150~500KB, 3×나 컬러에서는 그보다 2~3배 정도입니다.

이미지로 만든 스캔 PDF의 용량을 줄이는 방법

  • 컬러 도장이나 신분증 사진처럼 색이 의미를 가질 때가 아니라면 컬러 대신 회색조를 사용하세요.
  • 작은 글자가 깨지지 않는 한 해상도는 2×를 유지하세요. 3×는 픽셀 수를 대략 두 배로 늘립니다.
  • 입자감이 JPEG 용량을 키우므로 노이즈를 0.05–0.1로 낮추세요.

보내기 전에 스캔 PDF를 어떻게 확인하나요?

스캔 PDF는 일반 PDF 뷰어에서 100%로 확대해 가장 작은 텍스트, 숫자, 서명란을 읽어 확인하세요. 그런 다음 페이지 수, 방향, 파일 용량을 점검하세요. 2분이면 끝나는 확인으로 받는 사람이 파일을 거절하기 전에 읽을 수 없는 숫자를 미리 잡아낼 수 있습니다.

  1. 가독성. 100%와 200%로 확대하세요. 날짜, 금액, 계좌번호의 모든 숫자가 명확하게 보여야 합니다.
  2. 방향. 가로로 넓은 이미지는 가로 A4 페이지가 되고 세로로 긴 이미지는 세로 페이지가 됩니다. 페이지가 옆으로 나왔다면 원본 사진을 먼저 회전하세요.
  3. 여백. A4와 비율이 다른 이미지는 양쪽에 흰 여백이 생깁니다. 스캔본에서는 정상이지만 아주 좁은 영수증은 페이지에서 작아 보이므로 바짝 잘라내세요.
  4. 파일 용량. 업로드를 시작하기 전에 포털의 제한과 비교하세요.

결과물이 이미지로만 되어 있다는 점을 기억하세요. 텍스트는 선택 가능한 문자가 아니라 픽셀입니다. W3C 접근성 지침은 "텍스트를 스캔한 이미지로만 구성된 문서는 내용이 검색 가능한 텍스트가 아니라 이미지이므로 본질적으로 접근성이 없다"고 설명합니다. 받는 사람이 검색 가능한 텍스트가 필요하다면 이후에 OCR을 실행하거나 원본을 보내세요.

이미지 스캔본 PDF를 망치는 실수는 무엇인가요?

이미지 스캔본 PDF를 망치는 실수는 거의 항상 원본 사진이나 지나친 설정에서 나옵니다. 그림자, 사다리꼴로 나온 페이지, 보이는 탁자 가장자리, 최대치의 노이즈, 심한 흐림, 여러 도 단위의 기울기입니다. 각각은 스캐너가 아니라 "휴대폰 사진"이나 "필터"라는 신호를 보냅니다.

이미지를 스캔한 것처럼 만들어도 괜찮은 경우는?

이미지를 스캔한 것처럼 만드는 것은 문서가 본인 것이고 내용이 사실일 때 괜찮습니다. 직접 찍은 영수증, 본인이 서명한 양식, 본인이 쓴 편지 같은 경우입니다. 스캔 느낌은 겉모습만 바꿀 뿐입니다. 사본을 더 공식적으로 만들어 주지 않으며, 편집을 감추는 데 절대 사용해서는 안 됩니다.

정직한 사용스캔 효과는 파일이 진짜인지가 아니라 보이는 방식을 바꿀 뿐입니다. 본인 것이 아닌 신분증, 공식 기록, 증명서, 서명을 위조하거나 변경하는 데 사용하지 마세요. 일부 법원과 기관은 텍스트 검색이 가능한 PDF를 요구합니다. 예를 들어 플로리다 남부지방법원은 "CM/ECF로 전자 제출되는 소송 서류·주요 문서는 텍스트 검색이 가능한 PDF 형식이어야 한다"고 명시합니다. 이미지로만 된 파일을 보내기 전에 받는 쪽의 규정을 확인하세요.

타이핑된 문서라면 PDF로 내보낸 뒤 문서를 스캔한 것처럼 만드는 가이드를 따르세요. 필러 가이드는 모든 방법을 비교합니다.

이미지 스캔본 PDF: 자주 묻는 질문

다음은 처음 변환을 마친 뒤 사람들이 이미지 스캔본 PDF에 대해 가장 자주 묻는 질문입니다. 형식, 페이지 크기, 여러 페이지 파일, 휴대폰, 개인정보 보호, 기관이 결과물을 인정하는지까지 다룹니다. 모든 답변은 무료 도구가 실제로 작동하는 방식, 즉 소스 코드와 공개된 설정을 바탕으로 합니다.

JPG를 무료로 스캔본 PDF로 바꿀 수 있나요?

네. pdflookscanned.com/scan의 웹 도구와 Chrome 확장 프로그램은 무료이며 계정이 필요 없고, 직접 추가하지 않는 한 워터마크도 없습니다. JPG를 넣고 스캔 효과를 조정한 뒤 PDF를 다운로드하세요.

제 사진이 서버에 업로드되나요?

아니요. 변환과 스캔 효과는 pdf.js와 캔버스를 이용해 브라우저에서 로컬로 처리됩니다. 처음 방문한 뒤에는 사이트가 오프라인에서도 작동하는데, 이는 아무것도 처리를 위해 전송되지 않는다는 것을 간단히 확인하는 방법이기도 합니다.

스캔 PDF는 어떤 페이지 크기를 갖나요?

모든 이미지는 A4 페이지에 배치되며, 세로로 긴 이미지는 세로 페이지, 가로로 넓은 이미지는 가로 페이지에 맞춰 축소되고 가운데 놓입니다. 이미지 비율이 A4와 다르면 더 작은 종이를 실제로 스캔한 것처럼 양쪽에 흰 여백이 생깁니다.

여러 장의 사진을 하나의 스캔 PDF로 바꿀 수 있나요?

네, 두 단계로 가능합니다. macOS 미리보기(프린트 → PDF로 저장)나 Windows(인쇄 → Microsoft Print to PDF)로 이미지를 PDF 하나로 합친 뒤, 그 PDF를 스캐너에 넣으세요. 도구 자체는 이미지 1장당 PDF 1개를 만듭니다.

도구가 제 사진을 자르거나 반듯하게 펴 주나요?

아니요. 자르기, 기울기 보정, 원근 보정은 하지 않습니다. 먼저 휴대폰 사진 편집기나 아이폰 메모, 아이폰 파일, 안드로이드 카메라의 내장 문서 스캐너를 사용해 정리한 뒤 이미지를 불러오세요.

제 HEIC 사진은 왜 지원되지 않나요?

HEIC는 지원 형식(JPG, PNG, WebP, SVG, GIF, BMP)에 포함되지 않습니다. Mac에서는 미리보기 앱으로, Windows에서는 사진 앱으로 사진을 JPG로 내보내거나, 아이폰 카메라를 높은 호환성으로 설정해 바로 JPG로 촬영하세요.

사진을 스캔본 PDF로 바꿀 때 어떤 해상도를 골라야 하나요?

기본값인 2×를 유지하면 A4 페이지가 약 144dpi로 렌더링됩니다. 작은 글자, 도장, 서명이 있다면 2.5×나 3×(약 216dpi)를 선택하세요. 값이 높을수록 파일이 커집니다.

USCIS는 휴대폰 사진으로 만든 PDF를 인정하나요?

USCIS는 각 이미지가 선명하고 모든 텍스트를 읽을 수 있다면 PDF, JPG, JPEG 파일(최대 12MB)로 된 문서 스캔본이나 사진을 온라인 증빙으로 인정합니다. 본인 원본을 깔끔하게 스캔한 PDF는 이 형식을 충족합니다.

스캔 PDF 안의 텍스트는 검색할 수 있나요?

아니요. 각 페이지는 PDF 안의 JPEG 이미지이므로 텍스트를 선택하거나 검색할 수 없습니다. 받는 사람이 검색 가능한 텍스트를 필요로 한다면 이후에 OCR을 실행하거나, 규정이 요구할 때는 변환된 PDF를 보내세요.
