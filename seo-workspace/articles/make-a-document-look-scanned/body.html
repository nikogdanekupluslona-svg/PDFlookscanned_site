How do you make a document look scanned?

You make a document look scanned by turning each page into an image with scanner-like flaws: a small tilt, soft focus, light noise, gray tones and sometimes a warm paper cast. A browser tool does this in seconds, so a Word file or Google Doc can pass for a paper scan without printing anything.

A real flatbed scan is a photograph of paper. The glass is never perfectly clean, the sheet is never perfectly straight, and the sensor adds faint speckle. When you make it look scanned digitally, you reproduce those traits on purpose instead of by accident.

The output is also structurally different. According to James Madison University's digital accessibility team, "PDFs of scanned documents are often just images of documents, similar to digital photographs, and typically do not contain readable text." Our tool produces exactly that kind of file: every page becomes a JPEG image inside a new PDF, so text is no longer selectable, and links and form fields are gone.

Step by step: make a document look like a scan

The reliable way to make a document look like a scan has four steps: export the file to PDF, open the scan tool, adjust rotation, noise, blur and color, then download the new PDF. The PDF export is what keeps fonts, tables, logos and page breaks exactly where you placed them.

  1. Export the document to PDF. In Microsoft Word use File → Save As (or Export) → PDF. In Google Docs use File → Download → PDF document. In a spreadsheet, use Save as PDF or print to PDF. Skip this step only for plain text-only documents.
  2. Open the scan tool. Go to pdflookscanned.com/scan in any modern browser, on a computer or a phone, and drop the PDF onto the page. No account is needed.
  3. Adjust the scan settings. Start with the defaults (Rotate 1°, Blur 0.3, Noise 0.1, Gray), add 0.5° Rotate variance so pages tilt differently, and raise Yellowish to 0.2–0.4 if you want an older paper tone. Watch the live preview.
  4. Download the scanned PDF. Click download to save a new PDF in which every page is a JPEG image. Open it once in a PDF viewer to confirm text is no longer selectable and the pages read clearly.

The whole process usually takes under two minutes for a short letter or form. Longer files take more time because every page is rendered, filtered and compressed in your browser tab.

Should you upload DOCX or export to PDF first?

Export to PDF first whenever layout matters. The scan tool accepts DOCX files directly, but it extracts only the raw text and re-typesets it on A4 pages in Helvetica 11 pt with 0.75-inch margins. Fonts, tables, images, headers, logos and letterheads are dropped. A PDF is used as-is, so every detail survives.

We built direct DOCX support for convenience, not fidelity. It works well for a plain note, a list or a draft where only the words matter. For a letter on company letterhead, a filled-in form or a formatted report, direct upload produces a page that looks nothing like the original, which defeats the purpose.

How to make a Word document look scanned

To make a Word document look scanned, save it as a PDF from Microsoft Word, then run that PDF through the scan tool. Word's own PDF export keeps fonts, tables, headers, signatures placed as pictures and page numbers, which the scan effect then turns into realistic image pages.

Export a Word document to PDF

  1. Open the document in Microsoft Word and check the last page for stray blank pages.
  2. On Windows, choose File → Save As, pick a folder and set the file type to PDF. On a Mac, choose File → Save As (or Export) and pick PDF as the format.
  3. Keep the optimization at "Standard" for the sharpest source pages.
  4. Save, then drop the new PDF into the scan tool.

Microsoft Support explains that Office desktop apps can save directly to PDF with "Standard" quality for printing or "Minimum size" for smaller files. Choose Standard: the scan effect adds its own JPEG compression later, and starting from a sharper page gives cleaner letters after blur and noise.

Microsoft's page also describes a related option: "If fonts can't be embedded into the document, the PDF uses bitmap images of the text so that the PDF looks the same as the original document." That option alone does not create a scanned look, because the page stays perfectly straight and clean, but it shows that text can already become an image during export.

If Word has no PDF option on your computer, use the system printer instead. On Windows, print to the built-in "Microsoft Print to PDF" printer. On macOS, open the Print dialog and choose PDF → Save as PDF. Both produce a normal PDF you can make look scanned in the next step.

Tip for Word formsFill every field before export. Once you make a Word document look scanned, fields become part of a flat image and cannot be typed into again, so keep the original DOCX for later edits.

How to make a Google Doc look scanned

To make a Google Doc look scanned, download it as a PDF with File → Download → PDF document, then open that file in the scan tool. The downloaded PDF keeps the doc's fonts, images and page layout, so the scanned version matches what you see in the editor.

  1. Open the document in Google Docs and switch to Print layout view to see real page breaks.
  2. Choose File → Download → PDF document (.pdf). The file lands in your Downloads folder.
  3. Open the scan tool in a new tab and drop the PDF in.
  4. Adjust the settings, preview, and download the scanned copy.

Google Docs in the US usually defaults to Letter page size, while direct text uploads to our tool use A4. Exporting to PDF avoids that mismatch: the scanned file keeps whatever page size the doc had, which matters if the recipient prints it on Letter paper.

The same route works on a phone. In the Google Docs mobile app, use Share and export or the Print option to save a PDF, then open pdflookscanned.com in the phone browser and pick the file from Files or Downloads.

How to make an Excel sheet or CSV look scanned

To make a spreadsheet look scanned, save the Excel workbook as a PDF first, then apply the scan effect. Dropping an XLSX or XLS file straight into the tool converts each sheet to CSV text on A4 pages, which removes gridlines, column widths, number formats, colors and charts.

Spreadsheets need more preparation than letters because they rarely fit a page by default. Before exporting, open Page Layout (or Page Setup), set the orientation, and choose "Fit all columns on one page" so a wide table does not split across several sheets of paper.

  1. Select the print area, set orientation and scaling, and preview the print.
  2. Choose File → Save As → PDF, or print to "Microsoft Print to PDF" on Windows or Save as PDF on macOS.
  3. Drop the PDF into the scan tool and keep Resolution at 2× or higher, because small table digits need more pixels.

A raw CSV file is the one case where direct upload makes sense. The tool prints the comma-separated values as plain text on A4 pages, which looks like a simple printout of data. If you want a formatted table, open the CSV in a spreadsheet app and export a PDF instead.

How to make a photo look like a scanned document

To make a phone photo look like a scanned document, first crop and straighten it with your phone's built-in document scanning, then drop the image into the scan tool. The tool places each JPG or PNG at its native size as one PDF page, adding gray tone, noise and blur, but it does not crop, deskew or fix perspective.

Built-in scanning handles the geometry. On an iPhone, Apple's Notes app can scan a paper document with automatic edge detection; the Files app offers the same scanner. Many Android phones include a document mode in the camera or in the Files app. Use either to get a flat, rectangular page before applying the scan look.

  • Light: shoot in even daylight without a flash, so there are no hot spots on glossy paper.
  • Angle: hold the phone parallel to the page; even with automatic correction, steep angles blur the far edge.
  • Background: place the sheet on a dark, plain surface so edge detection finds the corners.
  • Format: each image is scaled to fit and centered on an A4 page (landscape for wide images); JPG and PNG are embedded as-is, while WebP, GIF, BMP and SVG are converted to JPEG with the longest edge capped at 2,200 px.

One image file always becomes one single-page PDF. If a contract has five photographed pages, combine them first: on a Mac, open all images in Preview, select them in the sidebar and choose Print → Save as PDF; on Windows, select the photos, open Print in the Photos app and pick "Microsoft Print to PDF". Then make that combined PDF look scanned.

How to make it look scanned after signing a form

To make a signed form look scanned without printing, export the filled form to PDF, add your own signature image with the tool's stamp/signature option, set its position and size, and apply the scan effect. The signature is flattened into the page image together with the text, just like ink on a real scan.

The print-sign-scan loop is expensive in time and money. East Tennessee State University's library, for example, charges 10 cents per page for black-and-white and 25 cents for color printing, and you still need a scanner afterwards. Signing digitally removes both steps.

Add your signature or stamp image

  1. Sign a white sheet with a dark pen, photograph it, and crop tightly around the signature. A PNG with a transparent background looks best.
  2. In the scan tool, open the stamp/signature option and upload the image.
  3. Move it with the horizontal and vertical position controls onto the signature line, and adjust size until it matches the line length.
  4. Apply Gray colorspace, light blur and noise, and download. The signature now shares the same texture as the printed text.

Electronic signatures are widely accepted in the United States. The ESIGN Act states that "a signature, contract, or other record relating to such transaction may not be denied legal effect, validity, or enforceability solely because it is in electronic form". The IRS goes further and lists, among permissible e-signature forms, "A scanned or digitized image of a handwritten signature that is attached to an electronic record."

Courts can prefer the opposite. The U.S. District Court for the Northern District of California lets e-filers use a conformed "/s/" signature instead of scanning a signed page for many documents. Always follow the specific rules of whoever receives the form.

Use the scan look honestlyA scan effect changes how a page looks, not whether it is authentic. Only sign with your own signature and only stamp documents you are authorized to stamp. Never alter official records, IDs or someone else's signature. Some courts and agencies require text-searchable PDFs, so check the submission rules before you send an image-only file.

What settings make a text document look scanned?

For text-heavy documents, realistic settings are subtle: rotation of 0.5–1.5°, blur around 0.3, noise between 0.05 and 0.2, Gray colorspace and 2× resolution. Stronger values make the page look damaged rather than scanned and can make small print hard to read.

Every control has a defined range, so you can reproduce the same look later. Here are the controls with their ranges, defaults and our advice for letters, contracts and reports.

Rotate (−10° to 10°, default 1°)
0.5–1.5° looks like a sheet placed by hand. Above 3° reads as careless.
Rotate variance (0 to 10°, default 0)
0.3–0.8° gives each page a slightly different tilt, as in a real feeder scan.
Blur (0 to 1, default 0.3)
0.2–0.4 for body text in 10–12 pt; lower for small print and footnotes.
Noise (0 to 1, default 0.1)
0.05–0.2 adds sensor speckle without hurting legibility.
Brightness and Contrast (0 to 2, default 1)
Contrast 1.1–1.2 imitates a photocopier look; Brightness 1.05 lifts gray backgrounds.
Yellowish (0 to 2, default 0)
0.2–0.5 suggests off-white or aged paper; leave at 0 for crisp office paper.
Colorspace (Gray or Color, default Gray)
Gray for most office documents; Color only if logos or stamps must keep their color.
Border (on/off, default off)
Adds a thin dark frame line around the page, like the edge of a scanner lid.
Resolution (1× to 3×, default 2×)
2× is about 144 dpi; 3× is about 216 dpi for fine print, at a larger file size.

How to scan-effect multi-page and bulk documents

Multi-page PDFs are handled in one pass: every page gets the same settings, and Rotate variance adds a different random tilt to each page. For many separate documents, the bulk page at /scan/bulk processes several files and downloads them all as one ZIP, with one scanned PDF per source file.

Page count affects time and size. Each page is rendered at the chosen resolution and saved as a JPEG image, so a 30-page report at 3× takes noticeably longer and produces a much larger file than the same report at 2×. For long documents, 2× is usually the better balance.

Size limits matter when you submit files online. USCIS, for instance, limits each evidence file to 12 MB in online filing, and the Northern District of California asks filers to split exhibits above 50 MB. If your scanned PDF is too large, lower Resolution to 1.5× or split the source PDF before processing.

  • Bulk scan: open /scan/bulk, add all files, set shared settings, download the ZIP.
  • Chrome extension: the side-panel extension uses the same engine and accepts several files at once.
  • Consistency: use identical settings for documents that are meant to come from the same scanner.

How to check that the scanned copy looks real

Check a scanned copy in three passes: open the downloaded PDF and try to select text, zoom to 100% to read the smallest print, then view the whole page at arm's length to judge tilt and tone. A convincing result fails text selection, stays readable and looks evenly imperfect.

  1. Selection test. Press Ctrl+A or Cmd+A in a PDF viewer. Nothing should highlight, because each page is now an image.
  2. Legibility test. Read digits in dates, amounts and reference numbers aloud. These are the characters people check first.
  3. Consistency test. Scroll through all pages. Tilt should vary slightly, while tone and noise stay the same, as with one scanner session.
  4. Size test. Look at the file size and compare it with the limit of the portal or email service you will use.
  5. Metadata test. Open document properties. If the title or author still shows a draft name, edit it in the tool's metadata fields and export again.

The metadata step is easy to forget. The tool lets you set title, author, subject, keywords, producer and creator, so the properties panel can describe the document plainly instead of showing an old working title.

Mistakes that stop it from looking like a real scan

Most failed attempts to make it look scanned come from one of five mistakes: uploading a formatted DOCX directly, overdoing rotation and blur, mixing color and gray pages, using a low-resolution photo, or keeping identical tilt on every page. Each one is easy to avoid with the right route and settings.

Another subtle mistake is expecting the tool to add creases, folds, coffee stains or shadowed edges. It does not; it simulates a clean office scan with tilt, blur, noise, tone and an optional border. If a realistic office scan is your goal, that restraint is an advantage.

Finally, remember what the scanned copy loses. Hyperlinks, bookmarks, fillable fields and selectable text disappear. Keep the original file for editing and share the scanned version only where an image-style document is expected.

Make a document look scanned: FAQ

These answers cover the questions people ask most often when they want to make a document look scanned: using a phone, skipping the printer, what happens to links and text, file size, privacy and legal acceptance. Each answer is based on how the tool actually works today.

Can I make a document look scanned on my phone?

Yes. Open pdflookscanned.com/scan in the phone browser, pick a PDF or image from Files or Downloads, adjust the sliders and download. Export Word files or Google Docs to PDF in their mobile apps first so the layout is kept.

How do I make a document look scanned without printing it?

Export the file to PDF and apply a scan effect in the browser. The tool renders each page as an image with tilt, blur, noise and gray tone, so you get the look of a paper scan without a printer or a scanner.

Why did my Word file lose its formatting?

You uploaded the DOCX directly. Direct DOCX upload keeps only the text and re-typesets it in Helvetica 11 pt on A4 pages. Save the document as a PDF in Word and upload the PDF instead to keep fonts, tables and images.

Do hyperlinks still work after I make it look scanned?

No. Every page becomes a JPEG image inside a new PDF, so hyperlinks, bookmarks, form fields and selectable text are lost. Keep the original file if readers need clickable links.

Is the scanned copy text-searchable?

No, the output is image-only and the tool does not run OCR. If a court or agency requires a text-searchable PDF, submit the native PDF or run OCR separately in desktop PDF software.

How do I make it look like scanned in black and white?

Keep Colorspace on Gray, which is the default, and raise Contrast to about 1.2 for a photocopier-like look. Gray keeps soft tones; true black-and-white thresholding is covered in our grayscale guide.

Are my documents uploaded anywhere?

No. Processing runs locally in your browser with pdf.js and canvas, and files are not sent to a processing server. After the first visit the site also works offline as an installed web app.

Can I make a Google Doc look scanned without downloading it?

Not directly; the tool works with files on your device. Use File → Download → PDF document in Google Docs, then drop that PDF into the scan tool. The download takes a few seconds.

Why is the scanned PDF bigger than the original?

Text in the original is stored as compact vector data, while the scanned copy stores every page as a JPEG image. Lower Resolution from 2× to 1.5×, or use fewer pages per file, to reduce size.

Is a scanned-looking signature legally valid?

In the US, the ESIGN Act says a signature cannot be denied legal effect solely because it is electronic, and the IRS accepts a scanned image of a handwritten signature in its e-signature program. The recipient's own rules still decide, so check them first.

Can I combine several photos into one scanned PDF?

The tool turns each image into its own one-page PDF. Combine the photos into a single PDF first with Preview on a Mac or Microsoft Print to PDF on Windows, then make that PDF look scanned.
